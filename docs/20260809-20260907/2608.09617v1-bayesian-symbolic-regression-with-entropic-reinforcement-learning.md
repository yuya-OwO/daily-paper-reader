## 摘要
符号回归是寻找描述目标变量对一组输入随机依赖性的代数表达式的问题。与假设固定模型结构并拟合参数的回归形式不同，符号回归是在表达式空间上的搜索问题，例如使用算子库将表达式表示为抽象语法树。符号回归通常用于自然科学中数据有限且含噪声的场景。然而，搜索单个最佳拟合表达式无法捕捉关于表达式的认知不确定性，这推动了贝叶斯视角的出现，该视角能够进行不确定性量化并指定自然先验以约束搜索空间。在这项工作中，我们提出了ERRLESS（用于表达式结构采样的熵正则化强化学习），一种使用最大熵强化学习从给定数据的表达式后验分布中进行采样的可扩展方法。ERRLESS学习一个神经策略，通过逐步构建表达式的抽象语法树来顺序构造表达式。收敛时，该策略从后验中采样表达式。在测试时，可以通过该策略的 rollout 来采样表达式。我们证明了ERRLESS在费曼基准上取得了有竞争力的结果，同时生成简短且可解释的表达式。此外，我们证明了ERRLESS近似得到的后验预测均值与SMC基线相比实现了较高的决定系数（$R^2$），突显了贝叶斯视角在符号回归中的优势。

## Abstract
Symbolic regression is the problem of finding an algebraic expression describing a stochastic dependence of a target variable on a set of inputs. Unlike forms of regression that fit parameters assuming a fixed model structure, symbolic regression is a search problem over the space of expressions, represented, for example, as abstract syntax trees using a library of operators. Symbolic regression is typically used in settings with limited, noisy data in the natural sciences. However, searching for a single best-fitting expression fails to capture the epistemic uncertainty about the expression, which motivates a Bayesian perspective that enables uncertainty quantification and specification of natural priors to constrain the search space. In this work, we propose ERRLESS (Entropy-Regularized Reinforcement Learning for Expression Structure Sampling), a scalable approach for sampling from the posterior distribution over expressions given data using maximum-entropy reinforcement learning. ERRLESS learns a neural policy that constructs expressions sequentially by building up their abstract syntax trees. At convergence, the policy samples expressions from the posterior. At test time, expressions can be sampled by rollouts of this policy. We demonstrate that ERRLESS achieves competitive results on the Feynman benchmark while producing short and interpretable expressions. Additionally, we demonstrate that the mean of the posterior predictive approximated by ERRLESS achieves a high coefficient of determination ($R^2$) compared to an SMC baseline, highlighting the benefits of the Bayesian perspective in symbolic regression.

- 符号回归（Symbolic Regression, SR）的目标是在表达式空间（例如由算子库与变量、常量构成的抽象语法树）中搜索一个代数表达式，以尽可能准确地拟合给定数据中输入变量与目标变量之间的随机函数关系。

  - 不同表达式可能产生几乎相同的拟合效果；

- 核心问题：**能否用一种可扩展、摊销式（amortized）的计算框架，从关于表达式树、常量参数和噪声方差的后验分布中高效且近似无偏地采样，从而在保持良好预测性能的同时提供完整的不确定性量化？**

## 二、方法论：ERRLESS

### 2.1 核心思想

- 论文提出 **ERRLESS（Entropy-Regularized Reinforcement Learning for Expression Structure Sampling）**，将贝叶斯符号回归转化为最大熵强化学习（Maximum-Entropy RL）问题。
- 关键思路：训练一个**神经策略**，将“构造一个表达式树”建模为**顺序决策过程（sequential decision-making）**；策略每一步从合法 token 集合中决定下一个符号（变量、常量、算子或终止符）。
- 在最大熵 RL 框架下，通过**轨迹平衡（Trajectory Balance, TB）**目标训练策略。TB 学习目标是使策略的采样分布逼近于目标后验分布：
  \[
  p(T,\theta,\sigma\mid D)\ \propto\ P(T)\,p(\theta,\sigma\mid T)\prod_{i=1}^{N}\mathcal{N}(y_i;\,f_{T,\theta}(x_i),\,\sigma^2)
  \]
- 其损失定义为：
  \[
  L_{\mathrm{TB}}(T,\theta,\sigma;\phi)=
  \left[\log Z_\phi+\log \pi_\phi(T,\theta,\sigma)-R(T,\theta,\sigma)\right]^2
  \]
  其中 \(R(T,\theta,\sigma)\) 是未归一化后验对数密度（即奖励）。当该损失对所有样本同时达到 0 时，策略即收敛到后验采样器，\(\log Z_\phi\) 逼近对数配分函数（数据的边缘似然对数）。

### 2.2 关键技术设计

1. **自底向上的表达式生成（Bottom-up Generation）**
   - 不是传统 top-down 的先采样算子、后补叶子节点，而是按**后序遍历（postorder）**构造表达式序列，叶子（变量/常量）先出现，算子后出现。
   - 这样做有两个优势：
     - 部分中间状态本身是完整合法的表达式；
     - 新增算子时，其输入（子表达式）的物理单位已知，从而可以在每一步实时地施加量纲约束。
2. **物理单位约束与量纲分析**
   - 每个变量关联一个物理单位向量（7 个基本量纲上的指数向量）；每个算子定义了单位赋值函数 \(U_g\)，用于判断输入单位是否兼容并计算输出单位。
   - 这样在构造过程中能直接阻止如 \(\sin(\text{velocity})\)、对不同单位的量做加法等非法组合，显著缩减搜索空间。图 2 显示，加入单位约束后表达式搜索空间数量级大幅下降。
3. **结构先验与规则约束**
   - 对不合逻辑、冗余或不太可能出现的表达式加以禁止，如：
     - 禁止函数与其逆函数的复合（如 \(\sqrt{\square^2}\)）；
     - 禁止三角函数嵌套；
     - 禁止指数嵌套；
     - 禁止一元算子直接作用于常量。
4. **概率建模与策略参数化**
   - 策略采用 Transformer 架构（2 层、4 注意力头、隐藏维度 256）编码已生成 token 序列，再通过多个预测头输出：
     - 下一个动作（算子/变量/终止）的 logits；
     - 终止后常量采样所用高斯混合模型（5 个成分）的均值、协方差与权重；
     - 噪声方差 \(\sigma\) 采样所用 log-normal 混合模型的参数。
   - 先验设计：
     - 表达式树先验选取 unigram prior，运算频率取自物理公式语料（如 Encyclopaedia Inflationaris）；
     - 常量参数先验为高斯先验；
     - 噪声先验在合成数据上用 LogNormal，Feynman/Blackbox 上用宽半正态分布。
5. **Off-policy 训练与探索策略**
   - 使用“优先级重放缓冲（prioritized replay buffer）”、\(\epsilon\)-greedy 探索（\(\epsilon\) 从 1 退火到 0.05）；
   - 从 buffer 采样比例从 0.9 线性退火到 0.2；
   - 针对 TB 损失使用 Huber-like 梯度裁剪以稳定训练。

## 三、实验设计

### 3.1 数据集 / Benchmark

论文使用三类数据集：

1. **合成数据集（Synthetic dataset）**
   - 包含 7 个已知表达式，如 \(1/\sqrt{1-x^2}\)、\(2.37x+3.02\)、\(x+\sin(5.5x)\)、\(4.567\exp(x+y)\)、\(\sin(y+2.5x)\)、\(\sin x\cos y\)、\(\sqrt{x^2+y^2}\)。

2. **Feynman Symbolic Regression Database**

## 六、主要结论与发现

1. **ERRLESS 在后验建模上优于 SMC 基线**：在合成数据的后验预测均值 \(R^2\)（\(R^2_{\mathrm{PP}}\)）多项显著高于 PySIPS，且 ERRLESS 的后验样本在所有问题上均产生有限预测均值（PySIPS 经常因长尾发散样本导致预测均值坍塌，甚至出现 \(-8.9\times10^{53}\) 等极端值）。
2. **在 Feynman 基准上精度有竞争力且更简洁**：ERRLESS 的 AUC 为 0.924，优于 DSR（0.873）、PhySO（0.893）和 BSR（0.702），并接近 GP-GOMEA、Operon 等顶尖方法；同时生成表达式显著更短、参数更少，避免了许多方法为取得高 \(R^2\) 而膨胀表达式规模的问题。
3. **对噪声稳健**：ERRLESS 的 AUC 在目标噪声从 0.001 增加到 0.1 时几乎没有下降，而多数对比方法有明显退化。
4. **Blackbox 上具备精度-复杂度平衡优势**：AUC 达 0.350，优于 BSR（0.19）、AIFeynman（0.004），低于 XGBoost（0.625）；但 ERRLESS 产生的是可解释的紧凑公式而非黑箱模型。
5. **训练速度快**：由于无需内部循环做常量回归优化，ERRLESS 比大多数学习型符号回归方法快一个数量级。
6. **关于先验的语义解释**：先验偏向简洁表达式，有时会导致采样器选择与真值具有同阶泰勒近似但更短的结构（如选择 \(\cos(v/c)\) 替代 \(\sqrt{1-v^2/c^2}\) 形式），当数据量增大时似然会逐渐主导先验，使更复杂的真值结构被选中——这体现了贝叶斯框架下先验与似然权衡的自然性质。

## 七、优点与亮点

1. **贝叶斯与强化学习的结合很自然**：利用最大熵 RL 的固定点性质保证收敛时采样分布与后验一致，而不是只输出单一最大后验点，理论上清晰。
2. **自底向上的生成过程是重要创新**：
   - 使中间状态可为完整表达式；
   - 算子插入时输入单位已知，能够**在线施加物理量纲约束**，有效缩减搜索空间并提出一种“结构性剪枝”思想；
   - 可同时纳入长度限制、冗余规则、表达式的语义合理性约束。
3. **摊销式推断，避免逐表达式贝叶斯 MCMC 开销**：训练完后采样非常快；且避免了 DSR/PhySO 对所有候选做常量拟合的瓶颈。
4. **同时采样结构、常量与噪声方差**：对“表达式树 + 实数参数 + 噪声”的联合后验建模，比多数工作只对树结构做推断更进一步。
5. **消融设计较完整**：先验、目标函数、重放缓冲混合系数均有专门分析。
6. **评估指标设计合理**：区分了“单点最佳表达式测试 \(R^2\)”与“后验预测均值 \(R^2\)”，能揭示后验质量差异，这是很多 SR 论文未充分关注的。

## 八、不足与局限

1. **在复杂目标函数上性能仍有退化**：作者在 Limitations 中承认，当目标表达式高度复杂时，采样精度会下降。
2. **没有跨数据集摊销**：当前 ERRLESS 每次给定一个数据集都需要重新训练策略；虽然也有单数据集上的采样优势，但当面对海量小数据集时成本仍然较高。作者也将“跨数据集摊销”列入了未来工作。
3. **先验对强似然项的弱势数据时刻敏感**：在表达式真值很长而数据较少时，先验偏爱短近似表达式，可能导致偏离真实物理定律的选择（虽然这在贝叶斯意义上是合理的）。
4. **实验公平性与算力披露不够完整**：
   - baseline 结果较大程度依赖第三方基准实现与运行环境；
   - 未给出精确的算力总消耗、GPU 数量、单次训练 wall-clock 时间等指标；
   - Blackbox 只验证 12 个数据集，规模偏小。
5. **随机种子与统计汇报可加强**：表 1 只报告中位数，未给出方差/置信区间；某些 PySIPS 结果只运行成功 2/10 次，统计分析偏差风险较高。
6. **对运算符/物理单位库的扩展性尚未研究**：论文算法框架宣称不限于给定算子集合，但在实验中只覆盖固定的 12 个算子与 7 个基本量纲，能否扩展到更多算子（如积分、求导、特殊函数）或更复杂量纲关系未作验证。
7. **熵正则化训练的探索效率**：Feynman 基准中，ERRLESS 的 AUC 仍低于少数专用进化方法（如 GP-GOMEA、Operon），说明在有限评估预算下，后验采样的“充分探索-精准拟合”权衡仍未完全解决。
