## 摘要
互联系统已被广泛研究，重点在于子系统仅为输入-状态稳定（ISS）或无源系统的互联系统。本研究的重点在于自适应梯度方法中出现的互联系统。在自适应梯度方法中，一个子系统试图将代价函数的参数移向极小值点，而另一个子系统则致力于估计关于代价函数的某种导数信息，以帮助确定参数更新的方向。本研究考察了此类互联系统的实例，并利用不同技术为它们给出了多种Lyapunov函数构造。由此，自适应梯度优化器被证明是全局渐近稳定（GAS）的，并给出了用于构造验证这一性质的Lyapunov函数的方法。

## Abstract
Interconnected systems have been widely studied, with a focus on interconnected systems whose subsystems are solely input-to-state stable (ISS) or passive systems. The focus of this work is on the interconnected systems that appear in adaptive gradient methods. In adaptive gradient methods, one subsystem seeks to move parameters of a cost function towards a minimizer while the other subsystem works to estimate some derivative information about the cost function to help determine the direction of the parameter update. This work studies instances of such interconnected systems and gives various Lyapunov function constructions for them using different techniques. In doing so, adaptive gradient optimizers are proven to be globally asymptotically stable (GAS), and the methods for constructing the Lyapunov functions that certify this are presented.

## 2. 论文提出的方法论

- **抽象系统模型**：论文研究如下形式的连续时间自适应梯度系统（公式 12）：
  - 参数更新子系统：`ϑ̇ = -K(φ)∇J(ϑ)`
  - 辅助子系统：`φ̇ = ωℓ(q(ϑ) - φ)`
  - 其中 `J(ϑ)` 是代价函数，`K(φ)` 是自适应增益（正定对称矩阵），`q(ϑ)` 是用于估计导数/Hessian 信息的映射。
- **基本假设**：J 存在唯一最小点且不妨设为原点、梯度仅在原点为零、J 径向无界（可用 K∞ 函数上下界刻画）、q 连续且 q(0)=0。
- **关键观察**：
  - 参数子系统可用代价函数 J 本身作为 Lyapunov 函数，其导数严格递减；
  - 辅助子系统对输入 q(ϑ) 是 ISS 的，其增益可由 K∞ 函数 ρq 界定；
  - 因此整个互联系统可以用非线性小增益思想证明 GAS，但论文的目标在于构造显式 Lyapunov 函数。
- **三种 Lyapunov 函数构造方法**：
  1. **最大值型 Lyapunov 函数（一般情形，第 IV 节）**：
     - 构造：`V5(ϑ,φ) = J(ϑ) + max{ α_{ϑ,φ}(J(ϑ)), |φ|² }`，其中 `α_{ϑ,φ} = α_φ ∘ ρq ∘ α_{ϑ,1}^{-1}`。
     - 思想：将辅助子系统的 ISS 条件转化为基于 J(ϑ) 的阈值，当 `|φ|²` 超过阈值时惩罚 `|φ|²`，否则惩罚 `α_{ϑ,φ}(J(ϑ))`。
     - 分析：由于 max 函数在切换面上不光滑，需要使用 Dini 导数分别分析“高于”“低于”“位于”切换面三种情况，并证明上右 Dini 导数负定。
  2. **标量参数下的误差坐标 Lyapunov 函数（第 V-A 节）**：
     - 适用条件：n=m=1，J、q 均为一维函数。
     - 构造：引入误差坐标 `φ̃ = φ - q(ϑ)`，定义：
       `V6(ϑ,φ̃) = ϑ² + sgn(ϑ)∫₀^ϑ |q'(x)| dx + ln(1+φ̃²)`。
     - 思想：用符号控制的积分项补偿误差动力学中的耦合项，再利用 `sgn(J'(ϑ)) = sgn(ϑ)` 得到负定的导数上界。
  3. **积分变换型 Lyapunov 函数（多变量情形，第 V-B 节）**：
     - 前提：存在 γ 使得 `λ_min(K(φ)) ≥ γ(|φ|²) > 0`，且 γ 的积分径向无界。
     - 构造：
       `V7(ϑ,φ) = J(ϑ) + ∫₀^{J(ϑ)} [ρq∘α_{ϑ,1}^{-1}(r)]² / (4b_g(r)) dr + (1/(2ωℓ))∫₀^{|φ|²} γ(r) dr`，
       其中 `b_g(c)` 是 J 的某个水平集上 `|∇J|²` 的最小值。
     - 思想：通过积分变换和 Young 不等式，把辅助子系统输入项 `|q(ϑ)|²` 吸收进关于 J 的积分项，从而得到整体负定上界。
- **应用实例**：
  - 对 RMSProp 和 AdaHessian 的连续时间模型，分别给出推论（Corollary 1、2），直接由 Theorem 1 得到 GAS。
  - 用标量二次函数 J(ϑ)=ϑ² 展示上述方法产生的 Lyapunov 函数，验证其负定性。
