## 摘要
符号回归（SR）旨在从观测数据中发现简约的数学规律，然而传统方法往往难以应对物理上有意义表达式的巨大组合搜索空间。我们提出了InsightSR，一个将大型语言模型（LLM）作为引导层嵌入到PySR遗传编程引擎周围的框架。InsightSR并非依赖LLM直接生成表达式，而是通过两条互补路径渐进地转换搜索空间本身：语义种子路径（Semantic Seed Pathway）提出量纲一致的功能骨架，结构特征路径（Structural Feature Pathway）推荐非线性特征变换。这些转换在迭代过程中不断积累，拓宽了输入空间，并将符号搜索从在原始变量上构建深层表达式树转变为在丰富的、语义信息丰富的特征集上组装浅层树。一个生成后反馈循环评估候选解，根据经验效用对特征进行分类，并为下一次迭代精化引导，从而将发现过程从开放式生成转变为迭代式、自我纠正的精化过程。在三个基准测试中，InsightSR在Feynman基准上实现了95%的精确恢复率，在LLM-SRBench LSR-Transform任务上达到了80.18%的准确率，显著优于最先进的遗传编程和神经符号方法，同时在真实世界数据集上保持了强大的分布外泛化能力。

## Abstract
Symbolic regression (SR) seeks to discover parsimonious mathematical laws from observational data, yet conventional approaches often struggle with the vast combinatorial search space of physically meaningful expressions. We present InsightSR, a framework that embeds Large Language Models (LLMs) as a guiding layer around the PySR genetic programming engine. Rather than relying on LLMs to generate expressions directly, InsightSR uses LLMs to progressively transform the search space itself through two complementary pathways: a Semantic Seed Pathway that proposes dimensionally consistent functional skeletons, and a Structural Feature Pathway that recommends nonlinear feature transformations. These transformations accumulate over iterations, broadening the input space and shifting the symbolic search from constructing deep expression trees over raw variables to assembling shallow trees over a rich, semantically informed feature set. A post-generation feedback loop evaluates candidates, categorizes features by their empirical utility, and refines the guidance for the next iteration, transforming the discovery process from open-ended generation into iterative, self-correcting refinement. Across three benchmarks, InsightSR achieves a 95% exact recovery rate on the Feynman benchmark and 80.18% accuracy on the LLM-SRBench LSR-Transform task, substantially outperforming state-of-the-art genetic programming and neural-symbolic methods while maintaining strong out-of-distribution generalization on real-world datasets.

## 1. 核心问题与研究动机

- **背景**：符号回归（Symbolic Regression, SR）旨在从观测数据中直接发现可解释的数学规律，被视为自动科学发现的核心工具。然而，候选表达式的组合搜索空间随表达式复杂度呈指数增长，使该优化问题本质上是 NP-hard。
- **现有方法的缺陷**：
  - 基于遗传编程（GP）的方法（如 PySR）在庞大搜索空间中样本效率低，且缺乏物理约束机制，容易产生数值上精确但物理上无意义的表达式；
  - 基于深度强化学习和神经网络的方法（如 DSR、NeSymReS 等）依赖训练分布、分布外泛化能力差，物理约束多为硬编码，难以适应新物理情境；
  - 已有集成 LLM 的 SR 方法（如 LLM-SR、SR-LLM、LaSR、PiSR via LLM）往往只沿单一维度利用LLM——要么做结构假设生成，要么做输入空间变换，忽略了二者协同的潜力；同时还存在推理开销大、查询频率过高等问题。
- **核心洞察**：结构先验可以指导特征构造，工程化特征又可以简化拟合数据所需的结构形式——二者应当协同作用，而非彼此割裂。

## 2. 方法论：InsightSR 框架

### 2.1 核心思想

InsightSR 不依赖 LLM 直接生成最终表达式，而是将 LLM 作为 PySR 遗传编程引擎的"外层引导层"，通过两条互补路径**渐进式地重塑搜索空间本身**：

- **自上而下的语义种子路径**：提出量纲一致的函数骨架，提供物理信息热启动；
- **自下而上的结构特征路径**：推荐非线性特征变换并跨代累积，逐步拓宽输入空间；
- 配合"从结果中学习"的闭环反馈机制，将符号发现过程从开放式生成转变为**迭代式、自纠错的精化过程**。

### 2.2 优化目标

标准 GP 多目标优化形式：

\[
\min_{f \in \mathcal{F}} \quad L(f, D) = MSE(y, f(X)) + \lambda \cdot C(f)
\]

其中 \( C(f) \) 是表达式树节点数衡量的结构复杂度，\( \lambda \) 控制简约惩罚。

### 2.3 四阶段迭代循环

整个发现过程组织为每代（generation）执行的四阶段循环（见 Algorithm 1）：

1. **上下文初始化与单位合成（Contextual Initialization and Unit Synthesis）**
   - 从数据集元数据和问题描述中提取各变量的物理维度；
   - 对单位不明确的变量，LLM 根据问题语义和目标的物理角色推断可能维度；
   - 得到的单位约束贯穿整个搜索过程，所有量纲不一致的候选表达式在数值拟合开始前即被剪枝。

2. **并行引导策略（Parallel Guidance Strategy）**
   - **语义种子路径（Strategy A）**：LLM 生成候选表达式拓扑（含待优化符号常量的函数骨架），先审计其量纲一致性再注入种群；
   - **结构特征路径（Strategy B）**：LLM 基于历史性能建议高价值的非线性变换，如幂律项 \( x_i^n \)、超越映射 \( \sin(x_i) \)，扩充输入矩阵：
     \[
     X_{aug} = [x_1, \dots, x_d, \phi_1(x), \dots, \phi_k(x)]
     \]
   - 特征跨代累积，搜索从在原始变量上构建深层表达式树转为在已丰富特征集上组装浅层组合。

3. **PySR 引导搜索（Search with PySR）**
   - 引导信息包括三个组件：符号种子、算子偏好、增广特征矩阵 \( X_{aug} \)；
   - **复杂度偏置机制（Complexity-Biasing）**：修改每个表达式树的结构惩罚：
     \[
     C'(f) = \sum_{o \in f} (c_o + \omega_o)
     \]
     LLM 推荐的算子获得负偏置（复杂度折扣、促进其在 Pareto 前沿上的存活），LLM 认为物理上不合理的算子被正偏置惩罚；
   - **热启动机制**：保留上一代最优候选作为精英个体进入新种群，确保渐进收敛。

4. **多维评估与策略反馈（Strategic Analysis & Feedback）**
   - LLM 作为后置评论员，从数值精度、物理可解释性、变量覆盖完整性等维度评估 Pareto 最优候选；
   - 对特征空间做诊断分析，将每个工程化特征归类为"有效"或"无效"；
   - 累积到一个动态知识库中，在三个层面指导下一代：精化种子表达式、调整算子复杂度偏置、为特征路径排序新特征建议。

### 2.4 知识库的作用

知识库在每次迭代后累积成功模式与失败教训，使搜索逐步收窄至物理上有意义且数值精确的表达区域，实现渐进收敛。

## 7. 优点

- **设计新颖且定位精准**：换了一个切入角度——不引导 LLM 生成解，而是用 LLM 逐步改造搜索空间本身，有效规避了直接生成的不可靠性，同时发挥 LLM 的领域语义能力。
- **物理一致性内建**：单位合成与量纲审计从源头排除物理上无意义的候选，复杂度偏置以动态方式（而非硬编码约束）引导 GP 算子选择。
- **双路径协同**：语义自上而下 + 特征自下而上互相成就，避免此前单维引导方法的盲区，逻辑自洽且有说服力。
- **搜索效率架构合理**：将"深树搜索"转化为"浅树 + 富特征搜索"，直接降低 GP 求解的组合压力；LLM 只在代际间查询而非每步搜索，兼顾推理开销。
- **闭环自纠错机制**：知识库把成功模式与失败教训反馈给双路径，使搜索随迭代逐步聚焦，具备自我修正能力。
- **实验表现卓越**：在三个性质不同的基准上的显著提升（尤其 95% 精确恢复率与 80.18% LSR-Transform 精度），提供了有力的实证支撑。
- **真实场景 OOD 验证**：对分布外数据也进行了系统验证，相对仅靠数据驱动的方法有明显优势。

## 8. 不足与局限

- **未提供资源/算力消耗数据**：缺少 LLM 查询次数、推理 token 量、总运行时长及成本——这类信息对实际应用可行性评估至关重要；
