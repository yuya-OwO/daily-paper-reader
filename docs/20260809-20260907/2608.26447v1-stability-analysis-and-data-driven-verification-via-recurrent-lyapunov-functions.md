## 摘要
李雅普诺夫直接法是稳定性与控制理论的基石，但它依赖于寻找李雅普诺夫函数，这需要巧思或计算。一个关键难点在于，函数的每个子水平集都必须前向不变，这将其几何形状与系统的轨迹耦合在一起。我们通过用循环性（recurrence）替代不变性来放宽这一要求：如果从集合中出发的每条轨迹都在有限时间内返回，则该集合是循环的。这产生了循环李雅普诺夫函数（RLF）的概念，其子水平集只需是循环的。我们证明，在温和条件下，RLF能保证稳定性，并引入了能导出渐近稳定性和指数稳定性的更强概念。我们还给出了基于范数的逆定理：在相应的稳定性条件下，任何范数都是其实用版本的RLF。随后，我们开发了基于GPU的算法，仅凭轨迹数据即可验证（实用）稳定性，而无需李雅普诺夫函数。验证到ε-邻域内的稳定性只需O(log(1/ε))次轨迹评估，随着认证衰减率接近真实值，常数会增长，这揭示了内在的性能-成本权衡。

## Abstract
Lyapunov's direct method is a cornerstone of stability and control, but it hinges on finding a Lyapunov function, a task demanding ingenuity or computation. A key difficulty is that every sub-level set of the function must be forward invariant, coupling its geometry to the system's trajectories. We relax this by replacing invariance with recurrence: a set is recurrent if every trajectory starting in it returns within a finite time. This yields the notion of a Recurrent Lyapunov Function (RLF), whose sub-level sets need only be recurrent. We show that, under mild conditions, RLFs guarantee stability, and we introduce stronger notions yielding asymptotic and exponential stability. We also give norm-based converse theorems: under the corresponding stability conditions, any norm is an RLF for their practical versions. We then develop GPU-based algorithms that certify (practical) stability from trajectory data alone, without a Lyapunov function. Certifying stability up to an $\varepsilon$-neighborhood needs only $O(\log(1/\varepsilon))$ trajectory evaluations, with constants growing as the certified decay rate nears the true one, exposing an intrinsic performance-cost trade-off.

## 二、论文提出的方法论

### 1. 基本数学概念扩展
- **递归集（Recurrent Set）** ：集合 S 中出发的任意轨迹可无限次返回 S。
- **τ-递归集（τ-Recurrent Set）** ：集合 S 中出发的任意轨迹返回 S 的时间间隔不超过 τ > 0。
- **Containment Lemma**：对紧凑 τ-递归集，轨迹离开集合的逃逸距离可由 \(\max_{x∈S} \|f(x)\|\cdot h(\tau;L)\) 界住（取决于单边 Lipschitz 常数 L），由此将递归性转化为对轨迹的全局有界性保证。

### 2. Recurrent Lyapunov Functions（RLFs）
- 以"轨迹在有限时间返回并使 V 值下降"替代经典"V 沿轨迹单调递减"要求。
- **定义（简化）** ：对平衡点 x\* 附近集合 S，若 V 正定，且对任意 x∈S 满足
  \[
  \min_{s∈T_S(x;\tau)} V(\phi(s,x)) \le V(x)，
  \]
  则称 V 为 RLF；若在 S\{x\*} 上严格 `<`，则称为 Strict RLF（SRLF），进一步引入指数衰减因子 e^{αs} 时称 Exponential RLF（ERLF）。
- **关键稳定性结论**：
  - Theorem 1：RLF 存在可保证平衡点稳定性（通过构造不变集 I=Rτ(Ωβ)⊂Bε）。
  - Theorem 2：SRLF 可保证渐近稳定性（利用 ω-极限集使轨迹收敛到平衡点）。
  - Theorem 3：ERLF 可推导指数稳定性，收敛率 α 可由函数几何上的收缩条件与轨迹逃逸界的组合得到。

### 3. 范数逆向定理（Norm-Agnostic Converse Theorems）
- **ε-SRLF / ε-ERLF 定义**：在排除平衡点附近 ε-邻域的集合 Kε 上，要求递减条件，从而适应实际验证的需要。
- **Theorem 4**：若系统渐近稳定，则任意范数 \(V(x)=\|x-x^\*\|\\) 在 Kε 上是 ε-SRLF（需为稳定邻域选择有限 τ）。
- **Theorem 5**：若系统以 λ-指数稳定，则对任意 α<λ，\(V(x)=\|x-x^\*\|\\) 是 ε-ERLF（ε 可为零），且 τ 满足一个与 λ−α 和 C、几何半径相关的下界。
- **这些逆向定理表明"任何范数都自动是实用 RLF"**，因此无需手动寻找特殊形态的 V。这一特性将稳定性验证转化为对标准范数递归性质的数据验证问题。

### 4. 数据驱动验证算法
- **Theorem 8（局部验证准则）** ：对中心 x，若存在 t∈(0,τ] 使：
  \(e^{αt}(\|\phi(t,x)-x^\*\|\;+\;r e^{Lt}) \le \|x-x^\*\|\;-\;r\)，
  则 \(V(y)=\|y-x^\*\|\\) 在整个球 Br(x) 上满足 ERLF 条件。
- **分层加细网格覆盖设计**：将验证区域 Kε 分解为几何级数收缩的同心环层（Annuli），每层以半径 μRi 的球覆盖（μ,ρ 合理选择），从外到内分辨率逐渐提高，避免均匀 ε-网格的 O((R/ε)^d) 爆炸。
- **局部验证与并行化**：对每一以网格点为中心的球，用单条轨迹检验验证条件；若失败，则将该盒子递归细化（Split）。
- **核心算法**：
  - **Algorithm 1**：给定区域 QR 和排除半径 ε，找到保证 ϵ-ERLF 条件的最大衰减率 α。
  - **Algorithm 2**：给定目标衰减率 α，通过不断扩展与修剪寻找最大的可认证 α-吸引域。
- **Theorem 9（样本复杂度）** ：在一定指数稳定假设下，在 BR\Bε 上验证 ϵ-ERLF 条件至多需要
  \[
  N(ε)=O\left(\log\left(\frac{R}{ε}\right)\right)
  \]
  次轨迹评估，但常数项随 (λ−α) 减小而急剧增大——清晰揭示了性能（衰减率）与计算成本间的内在矛盾。

## 六、论文的主要结论与发现

1. **递归李雅普诺夫函数（RLF）理论上是充分的**：在温和的局部 Lipschitz 条件和紧凑集假设下，RLF 保证稳定性；SRLF 保证渐近稳定性；ERLF 保证指数稳定性，从而"递归性可有效替代不变性"。
2. **范数是自然的实际 RLF**：在渐近稳定或指数稳定的系统上，任意范数都会自动满足弱化版（ε-SRLF/ε-ERLF）递归条件，且此类弱化条件本身又足以产生实用稳定性（practical stability）。因此用户不必再为系统"量身定制"李雅普诺夫函数。
3. **数据驱动的验证窗口出现**：利用定理 8 单轨迹可对局部球验证 ERLF 性质，配合分层覆盖证明验证 \(B_R\setminus B_ε\) 上的稳定性至多需要 \(O(\log(R/ε))\) 次评估。相比同类学习方法（如 Boffi 等人的 Ω(ε^(−2d))），ε-依赖由多项式下降为对数。
4. **存在性能-代价权衡**：认证率 α 越接近系统真实指数 λ 时，所需常数随 (λ−α) 的倒数增大；即快速高精度认证与低采样复杂度不可兼得。
5. **算法实用性**：
   - Algorithm 1 相较于 SOSTOOLS 在两系统种均输出更高的保证收敛率 α，三维情况下耗时优势显著。
   - Algorithm 2 可在大范围内认证 α-吸引域，并通过修剪步骤保证了输出集合的安全性（avoid过度承诺）。

## 八、论文的不足与潜在局限

- **理论假设与现实之间存在一定缝隙**：RLF 验证要求预先知道系统在待验证集合上的单边 Lipschitz 常数 L、最大向量场模长等全局量。虽然这些量在紧集上有界，但实际估计起来并不简单。论文中测试的双线性系统和 Kuramoto 振荡器都允许解析地给出保守估计，而更一般的黑盒系统未必具备这种条件，因此“数据驱动”往往不是纯粹的未知向量场场景。
- **递归验证条件的局部性**：Theorem 8 给出的球上验证条件中包含了 \(r e^{Lt}\) 这一“鲁棒余量”，其代价是——为保证覆盖与验证成功，需要半径 r 取得足够小。当系统收敛速率 λ 与目标衰减率 α 很接近时，τ 需要取得非常大，导致单条轨迹的积分时间变长，实际计算量可能远超理论复杂度所暗示的水平。
- **对非指数稳定系统处理有限**：数据驱动验证算法严格围绕 ε-ERLF（指数衰减）设计；对于渐近稳定但不指数稳定的系统，只能先人为构造局部指数收敛速率，否则无法直接给出 α 并调用 Algorithm 1/2。这缩小了算法的适用范围。
- **缺少对采样噪声与扰动鲁棒性的分析**：论文假设可以精确获得轨迹值 \(\phi(t,x)\)。实际中，仿真会引入积分误差，若用于物理系统，观测噪声和输入扰动不可避免。理论上包含逃逸界似乎可推广至有界扰动情形，但作者没有给出明确的数据扰动引导下的误差传播界。
- **实验对比不够全面**：与 SOSTOOLS 相比，论文只在确定性双线性系统、给定区域上比较了 α 和耗时；没有比较吸引域的体积或安全半径；也未讨论 SOS 方法在高维下的可扩展性（尽管文中提到 SOSTOOLS 在高维可能失败，但缺乏实验支撑）。此外，每个 σ 值只测试了单个随机 B 矩阵实例，所有结论均缺乏统计误差线。
- **“范数是天然 RLF”的逆向定理具有保守性**：定理 4/5 在构造上依赖系统自身的稳定性和收敛率。对于未知的稳定系统，要想获得一个实用的 τ 下界，仍必须事先知道（或能够估计）收敛率 λ 与扭曲常数 C，而这本身往往是稳定性分析中最难获取的信息。因此，数据驱动验证的“可行性”依赖于额外的先验信息，并不是完全盲目可用的。

## 九、对领域的影响与可能的后续工作

1. **对稳定性分析范式的影响**：论文打破了“李雅普诺夫函数必须随系统向量场逐点下降”的固有认知。递归性作为比不变性弱得多的性质，给了研究者更多设计函数形式的自由度。后续研究完全可以尝试将这种方法与神经网络 Lyapunov 函数结合，将“逐点梯度条件”换为“轨迹沿线的最优值条件”，从而减轻训练成本。
2. **对数据驱动确认（Certificate）的推动**：文中将稳定性验证视作一个轨迹查询问题，并给出覆盖与组合的复杂度。这一思路与 “PAC verification” 和“risk-aware control”相关。尤其是对数样本复杂度，理论上大大优于随机采样方法。未来可结合高斯过程或贝叶斯优化，对动态未知的系统进行主动采样，以达到同样的保证。
3. **算法在更大系统的应用**：由于算法基于局部球覆盖并支持并行 ODE 求解，自然可扩展到中等规模（例如十维以下）的自治系统。关键瓶颈在于局部球的数量随维数增长的非均匀性，以及每一球的验证轨迹计算。通过更聪明的自适应网格划分或基于流形的降维，可能突破维度限制。
4. **可扩展至控制设计**：目前所有分析面向由解析向量场定义的自治系统。如果在输入处考虑参数化反馈控制器，则可通过将闭环向量场视为新向量场，调用同样的数据驱动框架进行控制性能验证；这或许是待开发的直接方向。

## 十、总结与个人评价

本文是一篇兼具理论深度与算法实践的工作。其最大贡献在于:**将稳定性分析的视角从“轨迹永远留在集合内”转向“轨迹必须周期性返回集合”，并从这种弱化的几何条件出发恢复了稳定性的经典结论**。围绕该定义，作者进一步证明了任意的范数在弱化意义下都能成为严格的李雅普诺夫候补，这使得“稳定性验证”与“李雅普诺夫函数构造”解耦——验证者可以直接用标准范数对预采样的轨迹做不等式检验，从而得到不依赖人工设计的、可保证的稳定性结论。

与此同时，作者坦率地指出性能（可验证衰减率 α）与计算复杂度之间的对数依赖系数冲突，这为实际应用提供了有价值的权衡视角。总体来看，论文方法在以下三方面是成功的:

- **简单性**：验证所需的工具只有 ODE 数值积分与范数不等式，没有凸优化或专用符号软件。
- **可扩展性**：算法天然并行，并在实验维度上可处理至 6 维系统。
- **可解释性**：基于逆向定理，用户对为何选取范数函数有清晰的理论预期。

但其适用范围仍受限于自治确定性系统、指数稳定前提与可估全局常数。针对复杂高维系统、非光滑向量场、含噪声采样等场景，仍需进一步深化研究。尽管如此，本文仍堪称“循环李雅普诺夫”思想的一次清晰、严谨且可操作的落地示范，为数值化、数据驱动化的非线性稳定性验证开辟了新的方向。
