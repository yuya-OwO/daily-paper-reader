## 摘要
表格数据作为机器学习中的核心数据格式，常常由于特征信息量不足而缺乏高性能建模所需的判别能力。自动化特征工程（AutoFE）通过自动化特征生成与选择克服了这一问题，确保了模型性能与运行效率。然而，传统的AutoFE由于依赖盲目的数学变换，往往产生可解释性较差的特征，而基于大语言模型（LLM）的AutoFE则面临挑战：需要昂贵的多轮迭代才能生成高效用特征以有效提升模型性能，同时存在固有的偏差与幻觉风险。在本文中，我们将符号回归与LLM相结合用于特征工程（SymboLLM-FE），以解决这些挑战。我们通过符号回归提取与目标高度相关、且能增强模型性能的数学表达公式，随后利用具有丰富先验知识的LLM对其进行精炼，以确保可解释性。在六个真实世界数据集和四个Kaggle竞赛上的实证结果表明，SymboLLM-FE优于现有AutoFE。SymboLLM-FE还通过采用基于统计先验的LLM精炼机制和个位数次LLM调用，解决了可解释性差与迭代次数多的双重挑战。

## Abstract
Tabular data, as a core data format in machine learning, often lacks the discriminative power needed for high-performance modeling due to insufficient feature informativeness. Automated Feature Engineering (AutoFE) overcomes this by automating feature generation and selection, ensuring both model performance and operational efficiency. However, traditional AutoFE often yield features with poor interpretability because they rely on blind mathematical transformations, while large language models (LLM)-based AutoFE faces challenges in requiring costly multi-round iterations to generate high-utility features to effectively enhance model performance, compounded by inherent risks of bias and hallucination. In this paper, we combine symbolic regression with LLMs for feature engineering (SymboLLM-FE) to solve these challenges. We extract mathematically expressive formulas strongly correlated with the target via symbolic regression, which can enhance model performance, then refine them by LLMs with rich prior knowledge to ensure interpretability. Empirical results on six real-world datasets and four Kaggle competitions demonstrate that SymboLLM-FE outperforms existing AutoFE. SymboLLM-FE also addresses the dual challenges of poor interpretability and numerous iterations by employing a statistical prior-grounded LLM refinement mechanism and single-digit LLM calls.

## 1. 核心问题与整体含义

**研究动机与背景：**
- 表格数据是机器学习中最重要的数据格式之一，广泛应用于金融、医疗等领域，但其原始特征往往存在信息量不足、难以捕捉隐性高阶交互作用的问题，导致下游模型预测性能受限。
- 自动特征工程（AutoFE）旨在自动生成和筛选特征以提升模型性能，但现有方法存在两类核心矛盾：
  - **传统 AutoFE**（如AutoFeat、OpenFE）：依赖预定义变换规则、盲目搜索或数学算子堆叠，虽能提升性能，但生成特征缺乏语义含义、可解释性差，无法满足金融因子挖掘、监管合规等需要逻辑可验证的场景需求。
  - **基于 LLM 的 AutoFE**（如CAAFE、OcTree等）：虽能利用领域知识生成语义清晰的特征，但存在两个关键问题：(a) 生成的特征往往缺乏判别力，需要与下游模型多轮交互验证、反复试错，迭代成本高昂；(b) 固有大模型幻觉与隐含偏差会导致生成无效或有害特征，影响模型可靠性。
- **核心研究问题**：能否设计一种 AutoFE 框架，同时获得高预测性能、高可解释性和低迭代开销？

## 2. 方法论

### 2.1 核心思想
提出 **SymboLLM-FE** 混合框架，将符号回归与 LLM 协同分工：
- **符号回归负责模式发现**——高效挖掘与目标变量强相关的显式数学公式，保证特征对性能的提升能力。
- **LLM 负责语义精炼**——将不透明数学公式转换为符合业务逻辑的、语义可解释的代码，保证可解释性。
- 关键定位：LLM 不是无约束的**生成器**，而是受统计先验约束的**精炼器**，从架构层面阻断幻觉与偏差。

整体框架为两阶段流水线：**公式构建（Formula Construction）+ LLM特征生成（Feature Generation via LLMs）**。数据集采用严格的按折划分协议：训练集仅供符号回归建公式，验证集作为LLM反馈调优环境，测试集仅用于最终评估，防止数据泄漏。

### 2.2 第一阶段：符号回归公式构建

**(1) 特征集采样（降复杂度）：**
- 若对所有非空特征子集逐一运行符号回归，复杂度为指数级 O(2ⁿ)。
- 提出 **Spearman 相关分析 + 扩展滑动窗口** 策略：
  - 先计算各特征与目标的 Spearman 相关系数并按升序排序（Spearman 较 Pearson 更稳健地度量非线性单调关系）；
  - 窗口大小从 ⌊n/2⌋ 递增至 n（扩展阶段），每个固定窗口大小下窗口逐个右移（滑动阶段）生成多个连续特征子集；
  - 候选子集总数上界为算术级数求和，将搜索空间从 O(2ⁿ) 降为 **O(n²)**（即 (n+3)(n+5)/8 等多项式上界）。

**(2) 公式生成：**
- 对每个特征子集 Sᵢ 训练一个符号回归模型，生成如 `add(mul(c1,c2),c3)` 的从特征子集到目标的公式 τᵢ；
- 建立**公式-特征库 R**，每个元素为三元组 (Sᵢ, P(Sᵢ), τᵢ)（特征子集、符号回归性能、公式）。

**符号回归实现细节：**
- 使用 gplearn 库（遗传规划范式）；
- 操作符集：14 个原语（add、sub、mul、div、sqrt、inv、neg、abs、max、min、sin、cos、tan、log），全部带保护操作避免数值不稳定；
- 关键超参数：种群规模 20,000、代数上限 120、锦标赛选择规模 100、交叉概率 0.9；
- 采用**简约压力正则化**（parsimony pressure，系数Ω经网格搜索选取），抑制表达式膨胀过拟合。

### 2.3 第二阶段：基于 LLM 的特征生成

**(1) LLM 引导的代码生成：**
- 将公式库 R 中的公式转为自然语言描述，连同数据集背景信息和代码生成提示词一起输入 LLM；
- 通过思维链推理，让 LLM 生成可执行的 Python Pandas 特征工程代码。

**(2) 下游预测器验证：**
- 执行生成代码得到新特征集，合并入原始数据后训练下游预测器，获得验证集性能分数。

**(3) 迭代特征精炼：**
- 将性能分数与生成代码反馈给 LLM 进行迭代优化，直到达到相对最优；
- 内置**特征预算控制**：动态剪除降低验证性能的特征；
- **冗余消除**：提示模板强制 LLM 给出删减理由，LLM 充当语义过滤器识别公式与原特征间的数学等价性，去除多重共线性；
- LLM 操作严格限定在统计验证过的子空间内，从机制上消除幻觉。

### 2.4 一个关键公式
优化目标：max P_f(C ⊕ g(C))，即通过 AutoFE 函数 g 生成新特征使下游模型 f 在扩展后的特征集上性能最大化。

3. **统计局限**：Credit-g、Ailerons 数据集上的性能优势未达统计显著水平，方法的普适优势需要更多数据集进一步证实；
4. **成本度量偏差风险**："仅4次LLM调用"未完整反映"单次调用内生成的代码块数/Token 消耗（数万Token/数据集）"的成本考量，也未对比不同 LLM 推理模型的实际部署价格差异；
5. **对LLM推理能力的依赖**：实验结果明确表明框架效果与 LLM 推理能力密切相关——强推理模型提升显著，这意味着使用弱模型时效果可能明显下降，在实际部署中需要考虑模型选型成本；
6. **评估细节透明性欠缺**：论文部分实验表格样例数较大、涉及较多随机种子与对比方法，但未报告总实验资源消耗或逐种子结果细节，不利于读者评估实验代价与方差全貌。
