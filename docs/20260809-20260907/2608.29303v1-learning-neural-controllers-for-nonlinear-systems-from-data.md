## 摘要
本文探讨了为未知非线性系统设计神经反馈控制器的问题。我们提出了一种间接的数据驱动框架，利用离线数据辨识系统动力学，在此基础上联合综合神经反馈控制器和神经李雅普诺夫函数。通过在控制器架构中集成硬饱和结构来强制执行输入约束。推导了鲁棒综合条件，以考虑辨识过程中的数据扰动。通过将SMT验证与平衡点附近的局部李雅普诺夫分析相结合，证明了形式稳定性。数值算例验证了所提框架的有效性。

## Abstract
This article addresses the problem of designing neural feedback controllers for unknown nonlinear systems. We propose an indirect data-driven framework that uses offline data to identify the system dynamics, upon which a neural feedback controller and a neural Lyapunov function are jointly synthesized. Input constraints are enforced by integrating a hard-saturation structure into the controller architecture. Robust synthesis conditions are derived to account for data perturbations during identification. Formal stability is certified by combining SMT verification with local Lyapunov analysis near the equilibrium. Numerical examples validate the effectiveness of the proposed framework.

本文的核心目标即在于：**构建一个间接的数据驱动框架，为未知非线性系统端到端地联合合成具有确定性稳定性保证的神经控制器和神经Lyapunov函数**，并同时处理输入约束与辨识数据中扰动带来的鲁棒性问题。

## 2. 核心方法概述

论文的方法体系可以拆解为“辨识 → 优化综合 → 形式化验证 → 扰动鲁棒性扩展”四个层面。

### 2.1 系统辨识（间接数据驱动范式）

- 假设系统的向量场可表达为**已知基函数库的线性组合**：f(x,u)=AZ(x,u)，其中A为未知矩阵；
- 通过系统辨识，从离线收集的数据对(X1,Z0)中恢复A的最小二乘估计：A = X1Z0†；
- 为了克服多变量系统中量纲差异大、不利于神经网络训练的障碍，论文引入**线性状态归一化**：z=Sx（S为按状态坐标上界构造的对角缩放矩阵），将感兴趣域X映射为良态单位超立方体，同时给出相应识别算法的归一化模型重建。

### 2.2 网络架构与优化目标

- 提出一种 **“硬偏差消除”网络架构**：将输出定义为NV(z)−NV(0)（或Nu(z)−Nu(0)），从构造上严格保证V(0)=0、ψ(0)=0，这比软惩罚更为鲁棒；
- 在正式联合训练之前，先对Vz(z)进行**预训练**，使其逼近目标二次型Vtarget=β‖z‖²，从而为后续的非线性优化提供一个优良拓扑初值，提高了联合训练的数值稳定性；
- 稳定性条件被转化为**基于样本的损失函数**：对V的正定性使用ReLU(ε·Ω(zk)−V(zₖ))惩罚，对V的时间导数负定性使用ReLU(LfV(zₖ)+ε·Ω(zₖ))惩罚；
- 损失函数采用**加权形式**：Ltotal=γ₁·LPD+γ₂·LND，其权重比对输入归一化的物理尺度进行了针对性调整。

### 2.3 反例驱动训练

由于稳定性要求对连续域上任意状态均成立，而经验风险最小化只能保证样本点有效，论文激活了三种反例搜索机制：

- **PGD投影梯度下降**：利用梯度信息在验证域内递归求解最大违规状态，并对更新施加投影算子以确保仍在域内；
- **GAN对抗生成网络**：以判定损失函数Ltotal替换传统判别器，把高斯噪声映射成候选反例；
- **PSO粒子群优化**：引入无梯度的随机搜索机制，解决饱和型激活函数和ReLU惩罚非光滑带来的梯度消失问题。

实际运行时，这三种反例生成器可灵活组合，在迭代中不断给训练集注入最坏情况样本。

### 2.4 形式化验证

论文采用 SMT验证与局部稳定性分析相结合的混合验证范式，以实现从全体样本到全连续域的逻辑“穷举”：

- 将Xz中的平衡点从一个小的排除球Bσ(0)中剔除，将待验证域划分为：
  - 外层**XSMT=Xz∖Bσ(0)**由δ-完备区间型SMT求解器（如dReal）完成全连续域的Lyapunov条件验证；
  - 内层Bσ(0)由系统线性化和SDP求解联合分析：若线性化矩阵Acl是Hurwitz的，则求解P≻0、γ的正定矩阵SDP，结合Hessian上界确定阈值σthreshold。只要σ小于该值，该局部域即可被严格证明稳定；
- 若SMT验证失败，返回的不可验证域子区间又被视为新的反例集D_SMT送回到训练损失中以驱动下一轮训练循环。

- 对于物理系统固有的执行器饱和约束，控制器输出经tanh(·)归一化至单位超立方体：

## 4. 论文主要结论

- 构建了从数据到模型、从模型到可验证稳定闭环的**一整套自动化管线**：系统辨识、状态归一化、联合神经元优化、反例增强训练、SMT检验、本地线性推导层层接力，输出的是一个带有**可计算稳定证书**的控制律；

### 6.2 算法潜藏限制

- 适用范围受限：论文中的自适应SMT证明只限定了在**紧域内**进行，当域延伸到无限空间或不支持超越函数的无理运算时，验证算法在理论上是不可判定的，故无法宣称全局性收敛；

### 6.3 扩展与应用之忧

- 运行时间较昂贵：训练+反例搜索+SMT循环对每个算例都需要进行反复的求解器调度，该论文未报告这些过程产生的开销，也并未讨论改进大规模高维状态可扩展性的对策；
