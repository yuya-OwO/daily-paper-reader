## 摘要
本文将数据驱动的非线性常微分方程（ODE）发现问题进行重新表述，并提出了一种新的可解释机器学习（ML）方法。该方法旨在仅从单条状态轨迹数据中，在没有系统物理先验知识的情况下学习非线性动力学的未知向量场。该方法与现有方法有两个根本区别：1）该方法的公式基于泛函分析与算子理论推导；2）代价函数在函数空间中构造为两个函数之间的距离（以积分形式），而非现有机器学习方法中使用的误差离散和。提出了一种增量学习算法，以在线方式处理新的训练样本，从而学习未知向量场。该方法能够从受迫和非受迫的自治与非自治（或时变）动力系统中发现未知向量场，并能同时发现作为时间函数的未知外部力与未知底层动力学。最后通过数值算例展示了所提方法的优势。

## Abstract
In this paper, the problem of data-driven discovery of nonlinear ordinary differential equations (ODEs) is recast, and a new interpretable machine learning (ML) method is proposed. The proposed method aims to learn the unknown vector field of nonlinear dynamics without prior knowledge of the system's physics from only one single state trajectory's data. The proposed method has two fundamental differences with existing methods: 1) the formulation presented in this method is derived based on Functional Analysis and Operator Theory, and 2) the cost function is constructed in the function space as a distance between two functions as an integral, instead of the discrete-sum of errors used in existing ML approaches. An incremental learning algorithm is proposed to learn the unknown vector field to handle new training samples in an online manner. The proposed method can discover the unknown vector field from both forced and unforced autonomous and non-autonomous (or time-varying) dynamical systems. The proposed method is able to simultaneously discover unknown external forces as a function of time and unknown underlying dynamics. Finally, numerical examples are given to demonstrate the advantages of the proposed method.

- **问题定义**：本文研究的是**非线性常微分方程（ODE）的未知向量场发现**问题，即从系统状态轨迹的采样数据中逆向辨识系统的底层动力学模型（亦称系统辨识、逆问题或全局向量场重构）。
- **核心挑战**：
  - 真实世界中大量过程（电路、等离子体物理、流行病学、神经科学、医学和生物系统）由非线性 ODE 描述，但非线性是动力学系统辨识中的关键难点。
  - 现有数据驱动方法（如 SINDy、符号回归、神经 ODE、PINN、Koopman 算子等）多依赖离散误差求和作为代价函数，将训练样本视为无序且互不关联的点，未能利用轨迹数据中固有的时序连续性与平滑性；同时许多方法属于黑箱模型，缺乏可解释性；神经网络类方法训练时间长、对超参数敏感；SINDy 等直接方法对数值导数近似敏感。
  - 现有方法大多只能处理自治系统，对非自治（时变）系统和带有未知外力的系统较难直接适用。
- **论文主张与意义**：提出一种新的**可解释机器学习方法（FINS，Functional-Analysis-Based Identification of Nonlinear Systems）**，在函数空间中构造积分形式的代价函数，将时序/连续关系嵌入学习框架，仅用**单条状态轨迹数据**即可在无物理先验下恢复由有限阶多项式表征的未知向量场。该工作为非线性乃至时变系统的数据驱动辨识提供了新范式，并具备在线增量学习能力。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

**（1）核心思想**

- 将 ODE 学习问题从传统的离散误差最小化重构为**函数空间中的积分误差最小化**：代价函数是两个函数之间的距离的积分，而非逐点误差的离散和。积分误差的引入能够：
  - 建模训练样本之间的**时间/序列关系**，符合物理系统固有的连续性和平滑性；
  - 直接估计 ODE 解的积分误差而无需显式 ODE 求解器（这与 NODEs 不同，不需要 Runge-Kutta 求解器在训练循环中）。
- 在数学上基于**泛函分析与算子理论**进行推导，建立可解释的学习框架。

**（2）问题建模与算子构造**

- 考虑的系统模型为：**ẋ(t) = f(t, x(t)) + F(t)**，其中 x 为状态，f 为未知非线性向量场，F 为外力和输入（已知或未知均可以）。
- 将 ODE 转化为积分形式：**x(t) = x(t₀) + ∫f(s, x(s))ds + ∫F(s)ds**。
- 定义线性积分算子 **T(f)(t) := ∫f(s, x(s))ds**（Lemma 1 证明其线性性）。与 Hammerstein 算子的区别在于：Hammerstein 算子在 f 已知时作用于 x，而 T 反过来在 x 已知时作用于 f，处理的是**逆问题**而非正问题。
- 在空间中定义了加权内积和范数：
  - 函数空间 L²φ(R×Rⁿ, Rⁿ)：内积带高斯权重 e^(−xᵀx)；轨迹空间 L²w(R, Rⁿ)：内积带递减权重 w(s)。
- 由于实际中无法精确重构连续轨迹，基于数据 Dt 定义有限时域的算子序列 T_k，并将问题化归为一系列最优化问题。

**（3）有限维逼近：Hermite 多项式**

- 理论依据：任何 L²φ 中的函数可展开为 Hermite 多项式无穷和。工程上截断为有限阶多项式近似。
- 选取 Hermite 多项式作为基函数，原因是它们是**在 R×Rⁿ 全空间上正交**（而非有界域），适用于整个实数域。
- 通过截断最高阶 N₁,…,Nₙ₊₁，得到系数矩阵 C 和基向量 H(x)，将无限维优化问题转化为有限维二次优化问题。

**（4）核心理论结果（定理与推论）**

- **Theorem 1**：求解上述最优问题可归结为求解无约束二次规划：
  **min C_kᵀQ_kC_k + P_kᵀC_k + U_k**
  其中 Q_k 为积分核矩阵，P_k 为线性项，U_k 为常数项（均是积分形式），Q_k 的结构为分块对角矩阵。
- **Corollary 1（凸情形）**：当 Q_k 半正定时，最优解可通过求解 n 组**线性代数方程** 2Q̃_kC^(l*) = −P^(l)_k 得到，即转化为标准最小二乘问题。
- **Remark 3（非凸情形）**：Q_k 非半正定时，需使用非凸优化算法（如模拟退火）。

**（5）增量学习算法（Algorithm 1）**

- 利用**梯形法则近似积分**（23式），推导出 Q̃_k 和 P^(l)_k 的递推更新公式（Corollary 2 和 Appendix F），实现新样本到达时只用**上一次的矩阵和当前样本信息**即可更新模型参数，无需重新处理旧数据。
- 此增量学习属于 Instance-Incremental Learning 范畴，解决了记忆限制、数据安全/隐私限制和可持续人工智能等需求（对应在线学习/增量学习三个动机）。
- 该方法对均匀和非均匀采样时间均适用（均匀采样时连续时间误差与离散误差成比例，非均匀时二者不同）。

**（6）稀疏变体：FINS_s**

- 为提升可解释性并符合物理系统通常仅包含少数关键项的先验，在 Corollary 1 的线性方程解空间中引入 **l0 范数稀疏约束**（即压缩感知/基数最小化问题），用 SINDy 中的时序阈值最小二乘思想求解，获得更简洁的模型表达。

**（7）适用范围的扩展说明**

- 适用于自治和非自治系统、受迫和无受迫系统；

- 与 SINDy、EDMD/KLT 对比，FINS 在无噪声时预测误差通常低 1–2 个数量级（如 Duffing 预测[3,25]秒，FINS 误差 0.03 vs SINDy 0.48 vs EDMD 13.72，见表2和表4）。
- FINS 能同时辨识**未知外力与底层动力学**（例4成功恢复 δt² 项并得到精确模型）。
- 增量学习算法使单个新样本的更新仅需极短时间（毫秒级以下），适合在线/实时应用中的动力学学习，相较于批处理方法具有显著优势。
- 含噪数据下 FINS 比 SINDy/FINS_s 鲁棒性更好；但加稀疏约束会降低抗噪性（FINS_s 对噪声和阈值敏感）。
- FINS 对非多项式项不能完全刻画，仍可正确恢复多项式部分（如 Mathieu 方程中 ẋ=y 可成功发现）。
- 计算复杂度分析表明：批处理情形复杂度为 O(kτ² + knτ + kn + k + nτ³)，增量处理每样本复杂度低，但随状态维度增加呈指数增长（可用分布式算法缓解）。

### 7. 优点

- **方法学创新性突出**：将 ODE 发现重新表述为函数空间的积分距离最小化（而非离散和），从根本上区别于现有 ML 方法；与 Hammerstein 算子的关系分析清晰，体现了较深的数学功底。
- **理论严谨性强**：给出线性算子引理、定理、推论以及附录中完整的一步步推导（包括梯形离散化和递推更新公式），不是“配方型”方法。
- **可解释性**：模型输出与 Hermite 多项式的系数直接对应，可将结果映射回显式的动力学表达式，避免了黑箱问题。
- **单轨迹学习**：仅需单条轨迹数据即可工作，优于神经算子方法（通常需上百条轨迹）和传统系统辨识方法（通常需要多次实验/多条轨迹）。
- **增量学习能力**：新数据到达时无需重新对所有旧数据做整体训练，适合流式数据场景，具备处理隐私/安全限制的现实意义。
- **应用范围广**：自治与非自治、有外力与无外力系统统一处理，能同时辨识未知外部输入。
- **与基线的对比公平**：对 SINDy、EDMD 设置了有利的候选函数集并在文中明确说明；额外对比了两种神经网络类 SOTA 方法并给出训练时间，证明在效率上有 10⁵ 倍的量级优势。
- **将“无导数计算”作为间接方法**：不要求估计时间导数（与 NODEs 类似），降低了对采样率和导数近似的敏感度。

### 8. 不足与局限

- **主要应用限制**：
  - 需要**完整的状态测量**（或输入-状态测量），不能从输入-输出数据中获得状态空间表示；
  - 对**非多项式向量场**只能部分恢复（只能发现处于 Hermite 有限生成空间中的分量），这在数学上有所证明但实际中有明显局限；例6/例7表明非多项式外力或向量场会导致显著的额外虚假项；
  - 面临**维度灾难**：所需基函数数量随维度 n 呈指数增长（N≔N₁=…=Nₙ₊₁ 时 τ=N^(n+1)），高维系统不可行，虽提到分布式算法但有额外的通信开销。
- **实验与验证方面的不足**：
  - 噪声实验只用了一种 SNR 和一次随机实现，鲁棒性结论缺少统计显著性支撑（作者在结论中也承认这点，提出需要更系统的数学证明）；
  - 高阶 Hermite 多项式选择会对数值稳定性产生不利影响，当前没有自动确定最优多项式阶次的方法（作者在结论中提到将开发自动搜索算法）；
  - 与 K 阶多项式基线对比时，Hermite 基函数的项数多于普通的单项式基函数（SINDy 的项更少），对 FINS 而言是一种不利条件；
  - 对更高维（n > 4）的混沌/空间扩展系统未做实验验证。
  - 论文摘要中标记的训练时间不明确，也未报告 GPU 使用情况细节。
- **稀疏版本的不足**：FINS_s 对稀疏阈值过于敏感；解决 l0 问题的算法（如凸松弛、迭代硬阈值）尚未与 FINS_s 所采用的通用 SINDy 阈值方法一起明确给出收敛性分析；非凸情形（Q_k 非半正定）下仅给出线性方程解作为驻点，缺乏全局最优保证。
- **理论基础尚未完善**：作者自认的几处空白：① 数据增加对收敛影响的数学证明还不够；② 噪声鲁棒性缺乏理论证明；③ 无限数据下 Algorithm 1 的收敛性质需要进一步研究；④ 对不同的正交基（如 Legendre、Chebyshev）的选择比较研究仍待完成。
