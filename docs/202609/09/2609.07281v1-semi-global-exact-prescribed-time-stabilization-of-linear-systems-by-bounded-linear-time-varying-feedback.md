## 摘要
本文研究了有界控制下线性系统的半全局精确预设时间镇定问题。为解决该问题，需要构造一个参数化的二次控制Lyapunov函数，其对应的水平集可以任意大（以实现半全局镇定），并且闭环系统极点的实部随着参数趋近于无穷而趋近于负无穷（以实现预设时间镇定）。通过提出一种基于嵌套参数Lyapunov方程（PLE）的方法实现了这一目标，在控制器设计阶段仅需求解两个线性矩阵方程，无需使用实时状态信息。在所提出的结构条件下，基于嵌套PLE的方法能够保证对于任意给定的有界初始条件集合，只要预设的镇定时间足够大，即可实现半全局精确预设时间镇定。提供了一个数值示例以证明所设计控制器的有效性。

## Abstract
This paper addresses the problem of semi-global exact prescribed-time stabilization of linear systems by bounded controls. To solve such a problem, one needs to construct a parameterized quadratic control Lyapunov function whose corresponding level set can be made arbitrarily large (for achieving semi-global stabilization) and such that the real parts of the poles of the closed-loop system approach minus infinity as the parameter approaches infinity (for achieving prescribed-time stabilization). This objective is achieved by proposing a nested parametric Lyapunov equation (PLE)-based approach, through which only two linear matrix equations need to be solved in the controller design stage without using real-time state information. Under the proposed structural condition, the nested PLE-based approach guarantees semi-global exact prescribed-time stabilization for any prescribed bounded set of initial conditions, provided that the prescribed settling time is sufficiently large. A numerical example is provided to demonstrate the effectiveness of the designed controller.

  - 预设时间控制要求系统状态在预先指定的有限时刻精确到达并保持平衡点，而非渐近趋近。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：
  - 构造参数化的二次控制Lyapunov函数 \(V(x)=2n\gamma x^T P(\gamma)x\)，使其满足两个关键条件：
    1. 当参数 \(\gamma\to 0^+\) 时，\(P(\gamma)\to 0\)，从而水平集可任意大（半全局性）；
    2. 当参数 \(\gamma\to\infty\) 时，闭环极点实部趋于负无穷（预设时间收敛性）。
- **关键技术——嵌套PLE方法**：
  - 提出两个“嵌套”的RICCATI型代数PLE：
    \[
    A^T X + X A + X B B^T X = \gamma X,
    \]
    \[
    (A+BB^T X)^T Y + Y(A+BB^T X) - Y B B^T Y = -\gamma Y,
    \]
    并定义 \(P = Y - X\)。
  - 两个PLE通过线性化（令 \(\tilde X=X^{-1}\)、\(\tilde Y=Y^{-1}\)）转换为两个**线性矩阵方程**，只需离线求解，控制阶段无需实时解方程。
  - 证明 \(P(\gamma)\) 具有以下性质：
    - 正定性； 
    - 闭环极点 \(\lambda_i(A-BB^TP)=\lambda_i(A)-2\gamma\)；
    - \(\operatorname{tr}(B^T P B)=2n\gamma\)；
    - 满足Lyapunov不等式与导数界的性质，特别地 \(\lim_{\gamma\to\infty}\lambda_{\max}(P)/\gamma^{2\mu_c-1}=c_1\)、\(\lim_{\gamma\to0}\lambda_{\max}(P)/\gamma=c_2\)。
- **控制器设计**：
  - 采用线性时变状态反馈加标准饱和函数：
    \[
    U(t,x)=-\left(\frac12+\eta\right)B^T P(\gamma(t))x,\quad \gamma(t)=\frac{T}{T-t}\gamma_0,\quad \eta\ge0.
    \]
  - 实际输入为 \(u=\sigma(U)\)。
  - 根据初始集合 \(\Omega\) 选择足够小的 \(\gamma_0\) 使得 \(\Omega\subseteq E(\gamma_0)\)，并给出预设时间下界条件：
    \[
    T > \frac{2n+\delta_c}{2n\gamma_0}.
    \]
  - 通过构造Lyapunov函数并利用Lemma 3的精确有限时间稳定性判据证明闭环系统的精确T-FTS性质，并给出状态与控制范数的显式指数（多项式）衰减界。
- **实现细节**：PLE可转化为Kronecker积形式的线性方程组，得到 \(P(\gamma)\) 的显式有理/多项式表达式，便于直接求值。

## 6. 论文的主要结论与发现

- 在 **(A,B)可控且开环特征值均在闭左半平面** 的条件下，系统可通过**有界线性时变反馈**实现半全局精确预设时间镇定，前提是预设时间大于某个与初始集合有关的阈值（充分条件）。
- 核心原因在于**嵌套PLE构造的 \(P(\gamma)\) 可在 \(\gamma\to0\) 时趋于零，在 \(\gamma\to\infty\) 时使闭环极点趋向负无穷**，克服了传统PLE方法在存在稳定极点时γ无法任意小的困难。
