## 摘要
公式化Alpha发现是一个依赖于池的符号搜索问题，其中信息丰富的反馈主要在完整表达式被评估时观察到。这种延迟反馈产生了两个相互耦合的困难：保留的Alpha池并未保留已实现评估反馈的完整历史，并且中间构建动作的价值是不确定的，因为其后果取决于最终完成的公式。我们引入了AlphaRJM，通过奖励跳跃记忆（一种事件驱动的潜在状态，在符号构建期间保持不变，仅在终端评估事件时使用已实现的池奖励和评估结果进行更新）以及一个动作条件的SDE回报批评者（用随机粒子表示未来的折扣发现回报）来解决这些困难。粒子通过其均值和不确定性指导动作选择，并通过结合能量距离匹配、均值校准和跳跃正则化的分布贝尔曼目标进行学习。实证上，AlphaRJM在多个股票宇宙、预测时间范围和随机种子中提供了强劲且稳定的改进，而消融实验确认了持久评估历史、随机回报建模和分布监督的互补作用。

## Abstract
Formulaic alpha discovery is a pool-dependent symbolic search problem in which informative feedback is observed primarily when a complete expression is evaluated. This delayed feedback creates two coupled difficulties: the retained alpha pool does not preserve the full history of realized evaluation feedback, and the value of an intermediate construction action is uncertain because its consequence depends on the formula eventually completed. We introduce AlphaRJM, which addresses these difficulties through Reward-Jump Memory, an event-driven latent state that remains fixed during token construction and updates only at terminal evaluation events using the realized pool reward and evaluation outcome, and an action-conditioned SDE return critic that represents future discounted discovery returns with stochastic particles. The particles guide action selection through their mean and uncertainty and are learned using a distributional Bellman objective combining energy-distance matching, mean calibration, and jump regularization. Empirically, AlphaRJM delivers strong and stable gains across multiple equity universes, forecasting horizons, and random seeds, while ablations confirm the complementary roles of persistent evaluation history, stochastic return modeling, and distributional supervision.

## 一、核心问题与研究动机

- 公式化 Alpha 发现（Formulaic alpha discovery）的目标是从历史市场数据中自动挖掘可解释的符号表达式（即 Alpha 因子），使其对未来股票收益具有预测能力。
- 该问题本质上是**依赖已构建 Alpha 池的符号搜索问题**：一个候选公式的价值不是孤立的，而是由其**对现有因子池的边际贡献**决定（如 AlphaGen 提出的协同池奖励）。因此，搜索过程中必须考虑池的演化。
- 论文指出该任务存在**两个耦合的延迟反馈难题**：
  1. 搜索环境仅在完整表达式被评估时返回信息（延迟终端反馈），而**已评估的历史奖励和结果没有在状态中被完整保留**——即使两个搜索轨迹到达相同的因子池，其经历过的历史终端事件序列也可能不同，仅用当前池作为条件会丢失这部分信息。
  2. 中间 token 级构造动作的真实后果不确定：动作的好坏取决于将来完成的公式以及届时面对的池，因此**未来回报应该是分布式的，而不是单一确定值**。
- 现有工作（AlphaQCM、AlphaSAGE 等）虽改善了不确定性建模、结构表达或探索，但均未显式维护跨公式场景的持续终端评估历史，也未以随机动态过程刻画中间动作的未来回报分布。
- 为此，论文提出了 **AlphaRJM**，结合**事件驱动的奖励跳跃记忆（Reward-Jump Memory）**与**动作条件 SDE 回报判官（action-conditioned SDE return critic）**，以同时缓解上述两个问题。

## 二、方法论

### 2.1 整体框架

- 沿用了 AlphaGen 的语法化符号构造流程，在 token 级步骤上选取操作符、特征、常量或终止符。
- 每一步的搜索状态为：`st = (et, pt, Ht)`，其中：
  - `et`：部分表达式的编码；
  - `pt`：当前保留的 alpha 池的置换不变编码；
  - `Ht`：论文提出的持久化潜在记忆。

### 2.2 奖励跳跃记忆（Reward-Jump Memory）

- 状态：`H0 = tanh(W0[e0; p0] + b0)`，一次性初始化。
- 事件标记：在终端评估事件产生时（完成一个公式），事件编码器 `Mη` 将池奖励 `rt` 与分类结果 `ot`（`accepted / replaced / rejected / invalid`）映射为事件标记 `χt`。
- 跳跃计算：通过门控网络生成有界候选跳跃：
  - `Jt = Jmax * gt ⊙ ζt`
  - `gt` 为 sigmoid 门，`ζt` 为 tanh 方向，`Jmax` 限制跳跃幅度（实验中为 `0.02`）。
- 更新规则：
  - 若 `δt = 1`（终端事件）则 `Ht+1 = Ht + Jt`；
  - 否则 `Ht+1 = Ht`，即**在公式内部构造期间记忆保持完全不变**。
- 关键性质：记忆流不因公式完成而中断，可跨公式持续携带历史评估反馈，即使当前池没有任何变化。

### 2.3 动作条件 SDE 回报判官

- 对候选动作 `a`，构造条件向量：`qt,a = [et; pt; Ht; Aω(a)]`，其中 `Aω(a)` 为动作嵌入。
- 神经网络将其映射为四个标量：初始回报 `z0`、长期均值 `μ`、均值回复率 `κ>0`、扩散系数 `σ`（被限制在 `[σmin, σmax]`）。
- 定义条件 SDE（内部回报过程，非资产价格模型）：
  - `dZ = κ(μ - Z)dτ + σ dBτ`，τ 为内部扩散坐标，Bτ 为标准布朗运动。
- 通过 Euler–Maruyama 离散化（默认步数 `K=4`），采样 `M` 个粒子（默认 `M=16`），作为该动作未来折扣回报的分布近似。
- 动作选择分数：`St(a) = mean + cn * sqrt(variance + εnum)`，其中 `cn` 随公式场景数从 1 线性降到 0（即不确定性奖励系数渐变）。
- 加入 `εn-greedy` 策略：探索概率从 1 线性退火至 0.05。

### 2.4 分布贝尔曼学习

- 在线网络生成粒子 `Z_t`，目标网络对下一状态的最优动作生成粒子 `Z̄_{t+1}`。
- 贝尔曼粒子：`Y_t = rt + γ(1 - δt) Z̄_{t+1}`（终端步不跨场景自举，但记忆会持久化）。
- 损失由三部分组成：
  1. 经验能量距离 `LED`（CRPS 式样本分布匹配）；
  2. 均值 Huber 校准 `Lmean`；
  3. 事件跳跃正则化 `Ljump`。
- 总损失：`L = λED LED + λmean Lmean + βJ Ljump`。
- 由于记忆贯穿时间，采用**连续轨迹回放（sequence replay）**：从存储的记忆出发回放 burn-in 步骤后，再计算学习目标。
- 训练细节：容量 50,000 的缓冲，序列长度 16，其中前 8 步为 burn-in；AdamW，梯度裁剪 10，目标网络每 50 次优化同步一次。

- AlphaRJM 在 3 个主要股票池 × 4 指标（共 12 组）中取得 **10 个第一、2 个第二**；
