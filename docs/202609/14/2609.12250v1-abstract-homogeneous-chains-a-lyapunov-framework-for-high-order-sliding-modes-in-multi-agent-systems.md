## 摘要
本工作为多智能体系统中的一大类任意阶滑模算法构建了一个 Lyapunov 框架。我们引入了抽象齐次链，这是一类以共同凸性和齐次性为特征的非线性误差系统。针对该类系统，我们建立了任意阶的全局有限时间稳定性，构造了一个齐次 Lyapunov 函数，并推导了一种基于优化的递归增益建议流程。该框架弥补了现有动态平均一致性和分布式微分结果中的若干空白：它为任意阶 EDCHO 提供了一种基于数值优化的递归增益建议流程，将 REDCHO 的收敛性从局部扩展到全局，并为领导者-跟随者分布式微分提供了任意阶数值增益建议规则，而此前仅在一阶可用。它还提供了一种新的任意阶观测器，用于多领导者仿射编队跟踪，并具有全局有限时间收敛性。

## Abstract
This work develops a Lyapunov framework for a broad class of arbitrary-order sliding-mode algorithms in multi-agent systems. We introduce abstract homogeneous chains, a class of nonlinear error systems characterized by common convexity and homogeneity properties. For this class, we establish global finite-time stability for arbitrary order, construct a homogeneous Lyapunov function, and derive a recursive optimization-based gain-proposal procedure. The framework addresses several gaps in existing dynamic average consensus and distributed differentiation results: it provides a recursive numerical optimization-based gain-proposal procedure for EDCHO at arbitrary order, extends REDCHO convergence from local to global, and provides arbitrary-order numerical gain-proposal rules for leader-follower distributed differentiation, previously available only at first order. It also provides a new arbitrary-order observer for multi-leader affine formation tracking with global finite-time convergence.
