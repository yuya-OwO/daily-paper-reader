## 摘要
近期的智能体式符号回归方法日益依赖大语言模型来分析数据、选择科学操作，并在漫长的搜索轨迹中不断精化假设。在这类系统中，性能不仅取决于底层模型与搜索策略，还取决于支撑科学搜索的运行时基础设施。我们提出 SRHarness，一种面向智能体式符号回归的领域专用框架，其构建围绕三种机制：可组合的科学动作，为原始量、变换后的量以及由候选式导出的量提供统一接口；持久化的科学状态，保留已评估的假设并对外暴露面向模型的紧凑视图；以及轨迹生命周期管理，协调延续、分支、重启与终止。在 LLM-SRBench 上，在相同 LLM 主干条件下，SRHarness 在数值泛化与符号还原两方面均取得一致的提升。在使用 DeepSeek-v4-flash-0731 时，其在 LSR-Transform 上达到 93.69% 的符号准确率，而 SR-Scientist 为 62.16%；在去除科学描述与变量语义的匿名化变体上仍保持 72.97% 的准确率，而 SR-Scientist 为 39.64%。在相同的 DeepSeek-v4-flash-0731 主干下，SRHarness 也显著优于 Codex（72.97% 对 20.72%），并达到与使用 GPT-5.5 的 Codex 相当的性能；而仅仅为 Codex 提供相同的科学工具并不能复现这一优势。这些结果表明，有效的智能体式符号回归不仅取决于模型或工具，还取决于用于组织科学动作、累积假设与长时程搜索的结构化运行时支持。

## Abstract
Recent agentic symbolic regression approaches increasingly rely on large language models to analyze data, select scientific operations, and refine hypotheses over long search trajectories. In such systems, performance depends not only on the underlying model and search strategy, but also on the runtime infrastructure that supports scientific search. We introduce SRHarness, a domain-specific harness for agentic symbolic regression built around three mechanisms: composable scientific actions that provide a common interface over raw, transformed, and candidate-derived quantities; persistent scientific state that retains evaluated hypotheses and exposes compact model-facing views; and trajectory lifecycle management that coordinates continuation, branching, restart, and termination. On LLM-SRBench, SRHarness consistently improves both numerical generalization and symbolic recovery under matched LLM backbones. With DeepSeek-v4-flash-0731, it achieves 93.69% symbolic accuracy on LSR-Transform, compared with 62.16% for SR-Scientist, and retains 72.97% accuracy on an anonymized variant that removes scientific descriptions and variable semantics, versus 39.64% for SR-Scientist. Under the same DeepSeek-v4-flash-0731 backbone, SRHarness also substantially outperforms Codex (72.97% vs. 20.72%) and reaches performance comparable to Codex with GPT-5.5, while simply providing Codex with the same scientific tools does not reproduce this advantage. These results show that effective agentic symbolic regression depends not only on models or tools, but also on structured runtime support for organizing scientific actions, accumulated hypotheses, and long-horizon search.

# SRHarness 论文深度总结

## 1. 核心问题与整体含义（研究动机与背景）

- **符号回归（SR）的目标**：从观测数据中发现可解释的数学表达式，而非仅做黑箱拟合。传统方法（如遗传编程 PySR）搜索表达式组合空间；LLM 方法则借助科学知识、推理与代码生成引导发现。
- **智能体式 SR 的新范式**：近期方法把 LLM 从"在预定搜索流程中提出/修改方程"的组件，提升为**自主控制器**——根据中间证据自主选择科学操作（SR-Scientist、KeplerAgent、MOT-SR、DE、A-SR 等）。
- **被忽视的关键变量**：当 LLM 承担长时程方程发现时，系统表现不仅取决于底层模型与搜索策略，还取决于支撑科学搜索的**运行时基础设施**，即 agent harness（智能体框架/运行时）。
- **领域特殊需求**：SR 场景要求框架支持：异构科学操作间的可组合性、候选方程间一致的表示与评估语义、假设可被回溯/修改/复用，以及长时程轨迹的生命周期管理。
- **核心痛点**：现有智能体 SR 系统虽已实现部分支撑机制，但都是**围绕各自搜索策略定制**，而非独立的一层。这导致跨系统比较时，"搜索策略差异"与"框架差异"被混为一谈（引 Zhang et al. 2026c）。
- **论文主张**：harness 应被视为智能体式符号回归中的**一等组件**，与模型、工具并列。

## 2. 方法论：核心思想与关键技术

### 2.1 总体框架：三层分离

- **基础模型**：提供底层推理能力。
- **搜索策略**：组织科学发现过程。
- **Harness（SRHarness）**：提供执行与维持该过程所需的运行时支持，**不规定特定搜索策略**。
- 参照 Meng et al. (2026) 的 agent harness 综述，沿三个维度组织：**执行环境、认知管理、治理**，并对应实例化为三大机制。

### 2.2 机制一：可组合科学动作（Composable Scientific Actions）

- 动作形式化：`r = A(q; κ)`
  - `q`：智能体指定的科学量与选项（决定"做什么、作用于什么"）。
  - `κ`：框架管理的持久执行上下文（数据绑定、训练/验证划分、运行时配置），无需智能体反复重建。
- **表达式视图（关键设计）**：`q` 不限于固定数据集列，可以是当前数据上的表达式视图——原始变量 `x_i`、变换视图如 `log x_i` 或 `x_i/x_j`、候选导出视图如残差 `y − f(x)`。中间视图可直接作为后续动作输入，**无需物化新数据集或引入策略专属接口**。
- **共享候选–证据契约**：产出候选的动作统一记录表达式、评估结果、复杂度、诊断证据与来源（provenance），框架在接纳前施加统一的**有效性与评估语义**。
- **双通道输出**：机器可读结果与返回给模型的紧凑观察分离，使运行时能保留完整证据与元数据而不污染对话上下文。

### 2.3 机制二：持久化科学状态（Persistent Scientific State）

- 累积状态 `S_t` 存在于对话记录**之外**，存有已接纳候选及其量化评估、复杂度、支撑证据与来源。
- 状态**跨轨迹持久**：即使来源分支不再延续，候选仍可用；对话重启也不重置累积状态。
- **状态与视图分离**：模型面向视图 `v_t = P_ρ(S_t)`，`ρ` 为投影策略。实现中采用：
  - **拟合–复杂度 Pareto 视图**：突出候选方程间的权衡。
  - **Top-k 视图**：呈现领先的历史候选。
- 被省略的候选仍留在持久状态中，可进入后续视图。

### 2.4 机制三：轨迹生命周期管理（Trajectory Lifecycle Management）

- 管理四类轨迹转移：**延续（continuation）、分支（branching）、重启（restart）、终止（termination）**。
- 记录跨转移的来源信息（会话前驱、重启来源、跨分支传递的信息）。
- 与调度策略解耦；参考实现为 **R × C × L × K 调度器**（重启轮数 R、独立会话分支 C、精化深度 L、局部响应采样 K）。
- **Algorithm 1 流程（文字化）**：
  1. 划分训练集/验证集；初始化 `S ← ∅`。
  2. 对每轮重启 `r = 1..R`：取 `H ← TopK(S)`，构造初始提示 `p0`。
  3. 对每个分支 `c = 1..C`：复制 `p0` 为 `B`。
  4. 对每步精化 `ℓ = 1..L`：首步执行诊断；构造含 Pareto 视图 `P(S)` 的提示；LLM 采样 `K` 个响应；执行动作得到 `o_{1:K}`；评估并 `ADMIT` 入 `S`；选最佳响应 `k*` 继续对话，其余样本的诊断证据可并入上下文；记录 `(r, c, ℓ)`。
  5. 若完美拟合则提前返回最优；否则继续；最终返回 `BEST(S)`。
- 早停、中断或执行失败时保留最佳候选。

## 3. 实验设计

### 3.1 数据集 / Benchmark

- 主基准：**LLM-SRBench**，共 240 题，两个互补赛道：
  - **LSR-Synth**：128 个合成问题（物理 44、化学 36、生物 24、材料 25），评估 ID 与 OOD 数值泛化。
  - **LSR-Transform**：111 个由经典科学方程变换为不常见形式的问题，强调**精确符号还原**，保留科学描述与变量语义。
  - **LSR-Transform-Anon（作者自建）**：数值观测与目标方程不变，去除科学描述与变量语义（目标改名 `y`，输入改名 `x_1, x_2, ...`），仅保留通用输入/输出角色，用于隔离"数据驱动发现"与"语义先验回忆"。

### 3.2 对比方法

- **PySR**：非 LLM 的传统 SR 参照。
- **LLM-SR**：LLM 作为候选生成/变异算子的进化搜索。
- **IGSR**：影响分数引导的 LLM 方程搜索。
- **SR-Scientist**：最直接的智能体基线（LLM 自主控制分析、评估、精化）。
- **Codex**：同骨干对照（DeepSeek-v4-flash-0731）与 GPT-5.5；并测试"Codex + 相同科学工具"条件。
- 骨干：主要匹配 **DeepSeek-v4-flash-0731** 与 **GLM-5.3-flash**；另跑 DeepSeek-v4.1-flash、DeepSeek-v4-pro-0813、GLM-5.3 测可移植性。

### 3.3 指标

- **Acc0.1**：逐点误差 ≤ 10% 目标量级的比例（非严格的 AccAll 0.1）。
- **NMSE**：归一化均方误差，报中位数。
- **符号准确率 SA**：先做严格数值诊断（atol=1e-8、rtol=1e-6），再由 DeepSeek-v4-flash-0731 作为结构等价裁判，接受代数重排/域恒等式/系数取整，拒绝多项式、有理或 Taylor 替代物。
- 辅助：表达式复杂度、wall-clock 时间、token 用量、API 成本。

### 3.4 实验协议与配置

- 仅提供官方训练观测；所有 benchmark 测试观测在搜索与候选选择中**从不暴露**。
- SRHarness 固定配置 **R1-C1-L30-K1**，种子 26091320，训练集按 80/20 划分（split seed 42），候选按验证 MSE 排序。
- 统一动作集：statistics analysis、relationship analysis、read skill、evaluate formula、submit formula、constant fit、call pysr、call sindy、code executor。
- 所有本地复现方法使用统一的数值与符号评估管线；保留指向不可变原始日志的指针与哈希。
