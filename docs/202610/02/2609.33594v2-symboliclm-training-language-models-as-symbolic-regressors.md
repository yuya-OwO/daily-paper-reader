## 摘要
大型语言模型（LLMs）在科学推理方面已展现出良好前景，但科学发现最终要求直接从观测数据中推导出精确规律，即符号回归（SR）。由于概率性文本生成与SR所需的精确结构之间存在差距，这给LLMs带来了挑战。现有方法依赖复杂的外部脚手架，计算成本高昂，且将符号推理与模型本身分离。为克服这一局限，我们提出通过专门的数值-符号和物理监督，直接为LLMs赋予符号回归能力。我们引入PhysSymbArena，这是一个大规模基准，包含超过160,000个方程和18亿token的带有物理描述的数值-符号数据，可用于系统性训练与评估。基于PhysSymbArena，我们开发了SymbolicLM，通过数学与物理监督增强LLMs的符号回归能力。在推理阶段，我们进一步引入SymbolicSGA，一种利用定量反馈迭代改进生成方程的优化框架。在多个符号回归基准上的实验表明，SymbolicLM显著提升了结构恢复能力，同时保持了有竞争力的数值拟合性能。这些结果表明，符号回归可以作为LLMs的一种内在能力被显式学习。

## Abstract
Large Language Models (LLMs) have shown promising capabilities in scientific reasoning, yet scientific discovery ultimately requires deriving precise laws directly from observational data, known as Symbolic Regression (SR). This poses a challenge for LLMs due to the gap between probabilistic text generation and the exact structural requirements of SR. Existing approaches rely on complex external scaffolds, which are computationally expensive and separate symbolic reasoning from the model itself. To address this limitation, we propose to directly equip LLMs with symbolic regression capabilities through dedicated numerical-symbolic and physical supervision. We introduce PhysSymbArena, a large-scale benchmark containing over 160,000 equations and 1.8B tokens of numerical-symbolic data with physical descriptions, enabling systematic training and evaluation. Based on PhysSymbArena, we develop SymbolicLM, which enhances the symbolic regression ability of LLMs through mathematical and physical supervision. During inference, we further introduce SymbolicSGA, a refinement framework that leverages quantitative feedback to iteratively improve generated equations. Experiments on multiple symbolic regression benchmarks show that SymbolicLM substantially improves structural recovery while maintaining competitive numerical fitting performance. These results demonstrate that symbolic regression can be explicitly learned as an intrinsic capability of LLMs.

- **研究动机**：科学发现的本质是从观测数据中推导出精确的形式化定律，即符号回归（Symbolic Regression, SR）。LLM 虽在科学推理、数学推理等任务上表现强劲，但其能力根植于**概率性近似文本生成**，与 SR 所需的**高精度结构恢复**存在根本张力——即使一个算子、指数或变量依赖关系出错，误差也会在整个输入域上被放大。
- **现有方法的局限**：
  - 主流做法依赖**复杂外部脚手架**（如 agentic 工作流），让 LLM 提议候选公式、外部模块评估数值拟合，导致计算成本高昂（单个方程可能耗时数小时）。
  - 这种分工带来**反馈瓶颈**：标量数值残差难以转化为精确的代数结构修改，模型无法区分"拟合差"是源于函数形式错误还是参数未优化，容易陷入局部最优或生成无依据的表达式。
  - 模型的内部科学知识与符号回归过程被人为分离。
- **整体含义**：论文主张**直接将符号回归能力内化到 LLM 中**，使其能从原始观测数据中归纳定律，而非依赖外部搜索。这为 LLM 用于科学方程发现提供了新范式。

## 2. 方法论

### 核心思想
通过"**物理锚定的数据合成 + 数学-物理监督微调 + 轻量推理精炼**"三阶段统一框架，将通用 LLM 显式训练为符号回归器。

### 2.1 PhysSymbArena 数据集构建
- 每个样本形式化为三元组 **(D, C, f)**：数值观测 D、物理语义与量纲元数据 C、目标表达式 f。
- **数值方程生成**：基于随机树模拟流程合成表达式，树深度与算子从预定义库中随机抽取，再采样输入并求值得到观测数据。
- **物理锚定与量纲验证**：
  - 从 SymPy 整理 **127 个物理量**（力学、电磁学、热力学等），为变量和输出随机分配同域物理量。
  - 沿表达式树自底向上做量纲传播：加减需量纲相同、乘除按 `d(ab)=d(a)+d(b)`、幂运算 `d(a^r)=r·d(a)`、超越函数参数须无量纲。
  - 违反量纲一致性的分配被丢弃并重采样。

### 2.2 SymbolicLM 训练
- **第一阶段：指令微调（SFT）**
  - 输入提示 `Pi = [I; Vi]`，含符号回归指令、物理描述和结构化数值观测。
  - 目标表达式用**前缀表示法**（如 `f(x)=2sin(x)+3` → `[add mul 2 sin x 3]`）。
  - 标准 token 级交叉熵损失 `L_SFT`。
- **第二阶段：强化微调（GRPO）**
  - 设计**五类互补奖励**，采用门控设计：
    - **解析有效性奖励 R_parse**：能否被 SymPy 成功解析（0/1）。
    - **量纲一致性奖励 R_dim**：是否满足物理量纲约束（0/1）。
    - **符号结构相似度奖励 R_sim**：将常量替换为占位符 c 得到骨架，从算子、非线性函数、变量、常量、结构序列、复杂度 6 个维度比较（集合特征用 Jaccard 相似度）。
    - **符号等价奖励 R_equ**：骨架完全一致时给 1。
    - **数值拟合奖励 R_num**：用截断后的 R² 分数（`max(0, R²)`）避免训练不稳定。
  - 总奖励：`R = R_parse · R_dim · (w_sim·R_sim + w_equ·R_equ + w_num·R_num)`，即解析与量纲作为基本门控。
  - 每个 prompt 采样 G=8 个候选，组内归一化计算相对优势。

### 2.3 SymbolicSGA 推理精炼
- 受 SGA（ReAct 式科学发现框架）启发，但做了面向 SR 的改造：
  - **验证指标改为数值拟合度**，保留 top-5 候选进行迭代精炼。
  - **分支机制改为任务专用提示**而非温度调节：
    - **利用分支**：以 NMSE 最低的公式为父代，做单一小结构修改（改变量名或替换一元/二元项），要求保持主结构。
    - **探索分支**：从多个候选中重组有用子表达式，鼓励复用高质量候选共享的子结构。
  - 数值常数由 BFGS 外部优化，模型只负责结构。

## 6. 主要结论与发现

- **符号回归可作为 LLM 的内在能力被显式学习**，无需复杂外部脚手架。
- 数值-符号监督能有效将通用 LLM 转变为符号回归器：Qwen3-8B 从 R²=0.0179 提升到 SFT 后 0.7581。
- **RL 对齐提供 token 级模仿之外的额外监督**，改善结构恢复（Acc_τ 从 0.4375→0.4648）。
- **SymbolicSGA 的定量反馈能修正结构性错误**，在少次迭代内收敛到精确方程。
- 从 PhysSymbArena 学到的能力可**泛化到域外基准**（Feynman、Transform）。
- **物理信息主要提供语义与结构引导**，提升符号恢复精度而非数值拟合精度。

## 7. 优点

- **范式创新**：将 SR 从"外部搜索 + LLM 提议"转变为 LLM 的**内在能力**，避免了反馈瓶颈与高计算开销。
- **数据贡献扎实**：PhysSymbArena 规模（16 万方程 / 18 亿 token）远超现有基准，且首次同时支持训练与测试、兼容传统与 LLM 方法。
- **物理锚定设计巧妙**：通过量纲传播与重采样保证数据物理自洽，使模型能利用科学先验而非无依据数字。
- **多奖励门控设计合理**：解析/量纲作为硬门控，结构/等价/数值作为软奖励，兼顾语法正确性与结构精度。
- **SymbolicSGA 轻量**：不依赖温度调节，改用符号感知的任务提示，平衡局部精炼与全局探索。
- **泛化验证充分**：在多个独立构建的基准上验证了跨分布迁移能力。
