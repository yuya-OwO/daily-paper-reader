## 摘要
符号回归（SR）是一种数据驱动的科学发现方法，旨在从数据中搜索可解释的解析关系。近年来，大语言模型（LLM）也对科学发现产生了重大影响，使该过程各阶段的自动化成为可能。基于这些原因，利用LLM内嵌的科学知识和编程能力来解决SR任务的可能性已经出现，与传统方法相比展现出有前景的性能。我们提出EvoMO-SR，一种新颖的LLM驱动的SR框架，其中LLM生成方程骨架，其系数由外部优化器单独拟合。该框架包括多目标生存选择，通过平衡精度和复杂度来控制膨胀，以及子结构引导机制，利用候选可复用构建块对表达式进行变异。在LSR-Synth的八个域内和域外设置中，EvoMO-SR使用小型LLM模型（即Llama-3.1-8B-Instruct）在七个设置中取得了最佳精度。我们还通过两个基于规范化子树重叠和项匹配的符号精度指标评估了结构恢复，表明我们的方法具有更大的概率恢复出高精度的符号结构。

## Abstract
Symbolic Regression (SR) is a data-driven method for scientific discovery which searches for interpretable analytical relationships within data. Recently, Large Language Models (LLMs) have also had a significant impact on scientific discovery, enabling the automation of various stages of the process. For these reasons, the possibility of harnessing the embedded scientific knowledge and programming capabilities of LLMs to solve SR tasks has emerged, showing promising performance compared with traditional methods. We propose EvoMO-SR, a novel LLM-driven SR framework in which the LLM generates equation skeletons, with their coefficients fitted separately by an external optimizer. The framework includes a multi-objective survival selection which controls bloating by balancing accuracy and complexity, and a substructure guidance mechanism which mutates expressions with candidate reusable building blocks. EvoMO-SR achieves the best accuracy in seven of the eight in-domain and out-of-domain settings for LSR-Synth, using a small LLM model, i.e., Llama-3.1-8B-Instruct. We also evaluated structural recovery through two symbolic accuracy metrics based on canonicalized subtree overlap and term matching, showing that our method has a greater probability of recovering highly accurate symbolic structures.

- **LLM 带来的机会**：LLM 具有内嵌科学知识、编程能力和自然语言理解能力，可作为方程结构假设生成器，与外部数值优化器结合完成 SR。
- **核心问题**：如何利用 LLM 生成方程骨架，同时控制表达式复杂度膨胀，并提高数值精度与符号结构恢复能力。
- **整体含义**：论文提出 **EvoMO-SR**，将 LLM 嵌入显式种群式进化循环，使用多目标生存选择平衡精度与复杂度，并通过子结构引导机制复用进化过程中发现的可重用数学积木。其目标是在小规模 LLM 上也能取得优于传统 SR 和已有 LLM-SR 方法的表现。

## 2. 方法论

### 2.1 总体思想

- LLM 负责生成和变异**方程骨架**，即 Python 函数形式 `discovered_equation(Z, c)`，其中 `c` 为待拟合常数。
- 数值系数由外部优化器 **L-BFGS-B** 单独拟合。
- 整个搜索在显式进化循环中进行：初始化种群、拟合评估、父代选择、LLM 变异、子代生成、多目标生存选择、子结构档案更新。
- 同时维护两个记忆结构：
  - **种群 / Pareto Archive**：保存完整候选表达式及其精度—复杂度权衡。
  - **子结构档案**：保存从父代—子代差异中提取出的可复用加性子结构。

### 2.2 初始化与提示构造

- 初始提示 `P_init = {role + task, context, format}`：
  - 角色提示：要求 LLM 作为符号回归专家。
  - 任务提示：要求返回 NumPy 表达式，并强调平衡精度与复杂度。
  - 科学上下文：来自数据集元数据，例如变量物理含义。
  - 格式提示：要求输出描述、常数数量、Python 代码。
- LLM 除方程骨架外，还生成自然语言解释，说明表达式含义及增删改内容，用于后续提示和可解释性追踪。
- 初始种群大小 `n_parents = 10`，每个个体经 L-BFGS-B 拟合后用 NMSE 评估。

### 2.3 进化循环

- 总代数 100，每代子代数量 `n_offspring = 10`，因此总共生成约 1000 个表达式。
- 父代选择：主实验中采用 **random with replacement**，也支持 tournament、roulette。
- 变异提示 `P_loop = P_init ∪ {I_j, mutation}`，其中 `I_j` 为被选个体的表达式、描述和适应度。
- 每个变异迭代随机选择一种提示：
  - “Refine the current expression while preserving useful terms.”
  - “Propose a new expression completely different from the current one.”
- 子代生成后再次拟合系数并评估。

### 2.4 多目标生存选择

- 目标为：
  - **精度**：NMSE  
    \[
    \text{NMSE}=\frac{\sum_{i=1}^N(y_i-\hat y_i)^2}{\sum_{i=1}^N(y_i-\bar y)^2}
    \]
  - **复杂度**：表达式的 Python AST 数学节点数。
- 使用非支配排序构造 Pareto 前沿，再用拥挤距离保持多样性。
- 启用 `elitism=True`，父代和子代共同参与生存选择，避免优秀非支配父代被排除。
- 该方法用于抑制表达式膨胀，并保留精度—复杂度折中解。

### 2.5 子结构引导机制

- 每代结束后，扫描子代表达式，提取相对于父代新增的**加性子结构**。
- 子结构提取流程：
  - 用 SymPy 规范化表达式；
  - 必要时展开乘积以暴露加性项；
  - 转回 NumPy 语法；
  - 将可学习系数替换为占位符，并对可交换操作数排序去重。
- 维护固定长度档案，主实验大小为 10。
- 新子结构若档案未满则加入；若已满，则与档案中最差子结构竞争，依据关联子代的 NMSE 决定替换。
- 以概率 `p_sub = 0.5` 随机选取一个档案子结构，将其加入变异提示，引导 LLM 在变异中使用该子结构。

### 2.6 符号精度指标

- **SA_AST**：基于规范化 AST 子树签名的 Jaccard 相似度，衡量整体层次结构重叠。
  \[
  \text{SA}_{AST}(\hat f^*, f^*)=\frac{|T(\hat f^*)\cap T(f^*)|}{|T(\hat f^*)\cup T(f^*)|}
  \]
- **SA_Term**：基于规范化加性项签名的 Jaccard 相似度，忽略常数系数，衡量加性项匹配。
  \[
  \text{SA}_{Term}(\hat f^*, f^*)=\frac{|T_{Term}(\hat f^*)\cap T_{Term}(f^*)|}{|T_{Term}(\hat f^*)\cup T_{Term}(f^*)|}
  \]
- SA_AST 更严格，对额外或错误结构惩罚更强；SA_Term 对额外项更宽容，更强调是否恢复正确加性积木。
