## 摘要
尽管符号回归（SR）已成功用于科学领域以发现新方程，但其在金融估值中的应用受到若干限制。自然科学提供客观正确的关系，而金融估值构成了一类独特的符号发现问题，因为它允许多种有效视角，在非平稳市场条件下运行，并涉及带噪声的连续绩效信号。在这项工作中，我们提出 MUFASA（Multi-Agent Fundamental Analysis with Symbolic Adaptive learning，基于符号自适应学习的多智能体基本面分析），一个用于金融符号发现的分层多智能体框架。MUFASA 引入：（1）通过代表不同估值视角的专门智能体进行解耦方程发现；（2）一个元协调器，对市场上下文信息进行分层推理；（3）一种记忆机制，对统计绩效摘要（例如准确率、稳定性和尾部风险）进行推理，以在噪声反馈下指导学习。来自多个国家数据集的实验表明，与经典金融方法、金融大语言模型和 SR 方法相比，MUFASA 在估值任务上取得了当前最优性能，同时生成可解释的方程，我们将其与社区分享。我们还公开了跨演化迭代的蒸馏学习结果和依赖于上下文的策略权重，这可能为未来金融基本面分析研究提供有用见解。

## Abstract
While symbolic regression (SR) has been successfully used in science to discover new equations, its use in financial valuation is hindered by several limitations. Whereas the natural sciences provide objectively correct relationships, financial valuation constitutes a distinct class of symbolic discovery problems, as it admits multiple valid perspectives, operates under non-stationary market conditions, and involves noisy, continuous performance signals. In this work, we propose Multi-Agent Fundamental Analysis with Symbolic Adaptive learning (MUFASA), a hierarchical multi-agent framework for symbolic discovery in finance. MUFASA introduces (1) disentangled equation discovery via specialized agents representing distinct valuation perspectives, (2) a meta-coordinator that performs hierarchical-level reasoning over market context information, and (3) a memory mechanism that reasons over statistical performance summaries (e.g., accuracy, stability, and tail risk) to guide learning under noisy feedback. Experiments across datasets from multiple countries show that MUFASA achieves state-of-the-art performance on the valuation task compared to classical finance methods, financial large language models, and SR approaches, while simultaneously producing interpretable equations, which we share with the community. We also make publicly available the distilled learnings across evolution iterations and context-dependent strategy weights, which might offer useful insights for future research on financial fundamental analysis.

## 1. 核心问题与整体含义

- **背景**：符号回归（SR）在自然科学中已能自动发现物理定律等"唯一正确"方程；LLM 的加入进一步提升了假设生成与搜索效率。但金融估值（Fundamental Analysis, FA）本质上是一类**不同的符号发现问题**。
- **三大结构性错配**（作者明确归纳）：
  - **多重有效视角**：金融估值不存在单一真值方程，盈利、现金流、成长、资产等估值哲学可同时成立，搜索单一方程的现有 SR/智能体方法会限制表达力与泛化性。
  - **非平稳环境**：信号与结果的关系随市场 regime、行业而变化，"同样动作、不同结果"，使经验难以迁移复用。
  - **噪声、连续反馈**：候选表达式通过带噪声的连续绩效信号评估，而非二值对错；现有基于"成功/失败"的智能体记忆容易把噪声中的偶然模式误判为有效经验。
- **整体含义**：上述三个挑战在自演化循环的各个环节相互叠加，使金融符号发现整体更难。论文将金融估值确立为 SR 的一个独立问题类别，并提出分层多智能体框架 **MUFASA** 应对。

## 2. 方法论

### 2.1 问题形式化

- 给定公司集合与会计信息库 \(X_t\)，目标是对每家公司 \(i\) 预测其下一期（财季末）股价 \(y_{i,t+1}\)，并同时给出可解释的符号表达式 \(\tilde f\)。
- 与标准 SR 的两点差异：(a) 解释变量 \(x_{i,t}\subseteq X_t\) 未预先给定，需在发现过程中识别；(b) 关系是上下文依赖的，定义上下文 \(C(i,t)=(s(i), r(t))\)，即公司行业与市场 regime。目标为 \(\tilde f_{C(i,t)}(\hat x_{i,t}) \approx y_{i,t+1}\)。

### 2.2 解耦式符号发现（Disentangled Symbolic Discovery）

- **视角分解**：按金融文献中的估值哲学（现金流、盈利、成长、资产、质量等）定义一组视角 \(a\)，每个视角对应一个 LLM 智能体，视角本身作为归纳偏置约束假设空间，防止表达多样性坍缩。
- **假设生成**：每个视角智能体以 \(\tilde f^{(a)} \sim \pi_\theta(\cdot \mid p^{(a)})\) 迭代采样新方程；提示词 \(p^{(a)}\) 编码该投资哲学与从历史交互和统计反馈中累积的经验 \(Z^{(a)}\)。
- **工具使用（数据检索）**：先用语义检索获取候选变量名与描述，再检索对应数据；检索失败（不可用、覆盖不足）时获得结构化反馈并据此修正变量或表达式。
- **工具使用（代码评估）**：候选表达式作为可执行程序直接求值得到 \(\hat y^{(a)}_{i,t+1}\)；语法错误、非法运算、非有限输出等会返回结构化反馈并进入下一轮提示。
- **假设优化与评估**：将标量乘子/参数视为连续变量，用**差分进化**做数值优化，实现"LLM 定结构、数值方法拟合系数"的解耦；适应度用预测误差 \(L^{(a)} = \mathrm{MAPE}(\hat y^{(a)}_{i,t+1}, y_{i,t+1})\)。
- 流程见 Algorithm 1：初始化种子方程 → 循环{生成假设 → 检索 → 评估 → 优化 → 更新记忆与经验}。

### 2.3 分层推理（Hierarchical-Level Reasoning）

- 引入**元协调器智能体** \(\pi_\phi\)，针对每个上下文 \(C(i,t)\) 输出各视角智能体的相对重要性权重。
- 提示词 \(p_{\text{meta}}\) 包含当前上下文、各智能体层级表现 \(L^{(a)}\) 与累积经验 \(Z_{\text{meta}}\)；智能体先选择子集，再用 **SLSQP 约束优化**求解权重 \(\tilde w_{C(i,t)}\)。
- 聚合估值：\(\hat y_{i,t+1} = \tilde w^\top_{C(i,t)}\cdot \hat{\mathbf y}_{i,t+1}\)；协调器质量用 \(L_{\text{meta}}=\mathrm{MAPE}(\hat y_{i,t+1}, y_{i,t+1})\) 评估，从而在非平稳反馈下持续调整权重。

### 2.4 统计绩效记忆（Statistical Performance Memory）

- 不存储单一标量损失，而是为每个假设存储**多维统计摘要**，覆盖七类信息：
  - **准确率**：Mean/Median MAPE（降低对离群值与偏态敏感性）
  - **稳定性**：标准差、IQR、变异系数
  - **尾部风险**：p90/p95 误差、最差十分位均值
  - **复杂度**：变量数与算子数、预测覆盖率
  - **偏差**：平均符号百分比误差（MSPE）
  - **排序**：Spearman 秩相关
  - **校准**：按真实价格分位数的符号误差
- 从记忆中蒸馏经验 \(Z^{(a)}\) 指导后续假设生成（Algorithm 2 对应元协调器的记忆更新）。核心动机：单次评估可能被噪声主导，跨重复评估聚合才能估计方差与尾部行为等不可从单点观测获得的性质。

## 3. 实验设计

- **数据集 / 场景（五个股票市场）**：

- **Regime 定义**：沿用业界惯例，指数自最近低点上涨 ≥20% 为牛市，自最近高点下跌 ≥20% 为熊市。
- **Benchmark / 对比方法（五类）**：
  1. 传统机器学习：Random Forest、HistGBM、NeuralNet
  2. 符号回归：PySR、FunSearch、LLM-SR

  4. 经典金融估值：P/E、EV/EBIT、EV/EBITDA、P/B 的行业中位数，以及 DDM、FCFE、FCFF

- **统计检验**：Diebold–Mariano 检验（绝对百分比误差损失），采用 Newey–West HAC 方差估计（Bartlett 核，Andrews 规则选带宽）处理季度损失差的自相关，并用 Harvey–Leybourne–Newbold 小样本校正对 \(t_{T-1}\) 分布检验。

## 6. 主要结论与发现

- **性能**：MUFASA 在全部五个数据集上取得最优 MAPE，平均提升约 **19.65%**；相对更优的智能体基线（FinCon/FinVision）在各市场均胜出，平均误差降低约 **27.67%**；DM 检验显示所有成对比较均达统计显著（多数 p<0.001）。
- **基线观察**：Fin-R1 稳定优于 Fino1；传统估值比率（P/E、EV/EBIT）因结构简单而相对稳健但跨地区波动大；DCF 类方法（FCFF/FCFE）因依赖噪声较大的增长率与折现率估计而表现较差；SR 基线中 **PySR 反而强于 LLM 类 SR**，暗示 LLM 携带的科学先验在缺乏稳定支配律、关系上下文依赖的金融领域帮助有限。
- **消融结论**：解耦多视角优于单视角统一搜索；分层协调优于等权平均；统计记忆优于二值或仅 MAPE 记忆；"最佳单智能体"在 Russell 2000 上严重退化，说明依赖单一视角不稳定且事后选优不可行。
- **方程可解释性**：MUFASA 学到的是盈利乘数、DCF、账面倍数、相对估值、剩余收益等经典模型的"数据自适应变体"（保留核心结构 + 加乘修正项）；Fin-R1 基本复现 \(EPS\cdot PE\)；PySR 方程高效但金融上不透明；LLM-SR 只捕获粗粒度线性组合。
- **上下文规律**：权重随行业与牛熊 regime 显著变化（如重资产负债表行业更偏资产/现金流信号，稳定盈利行业偏盈利信号），且在不同地理市场间呈现可复现的趋势，说明学到的是可泛化的金融直觉而非数据集特异假象。
- **稳健性分析**：MUFASA 的 Spearman 秩相关最高，各分位数误差最低，跨估值四分位的 MSPE 更接近零（偏差更小、跨市场更稳定），在公用事业、工业、房地产、必需消费等基本面主导行业表现最佳。

## 7. 优点

- **问题刻画清晰且有理论价值**：把金融估值明确界定为 SR 的独立问题类别，并给出三条可操作的结构性挑战，为后续研究提供了清晰框架。
