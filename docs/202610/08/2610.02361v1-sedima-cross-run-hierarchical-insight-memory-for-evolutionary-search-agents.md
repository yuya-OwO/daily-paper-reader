## 摘要
由大语言模型（LLM）驱动的进化搜索是自动化程序与算法发现的一种强大范式，然而现有系统大多没有记忆：每次运行都从头探索，因此智能体会反复重新发现相同的改进，并再次遇到相同的死胡同。我们提出 SEDIMA，一种面向进化搜索智能体的持久分层洞察记忆。SEDIMA 将原始轨迹提炼为自然语言洞察，使用注意力加权质心按语义相似度对它们进行聚类，并检索相关指导以条件化未来的变异，从而跨运行和问题累积可迁移知识，而非局限于单条轨迹。作为一个即插即用模块，且不修改搜索算子，SEDIMA 在固定评估 100 个候选的预算下，将 AlgoTune 上的平均最终性能提升 5.5%，将 ALE-Bench LITE 上的平均最终性能提升 6.6%。在 OpenEvolve 下，SEDIMA 在五个评估骨干模型上达到基线最佳性能平均所需迭代次数减少 32.3%。

## Abstract
Large language model (LLM)-driven evolutionary search is a powerful paradigm for automated program and algorithm discovery, yet existing systems are largely memoryless: each run explores from scratch, so agents repeatedly rediscover the same improvements and re-encounter the same dead ends. We introduce SEDIMA, a persistent hierarchical insight memory for evolutionary search agents. SEDIMA distills raw traces into natural-language insights, clusters them by semantic similarity using attention-weighted centroids, and retrieves relevant guidance to condition future mutations, accumulating transferable knowledge across runs and problems rather than within a single trajectory. As a drop-in module that leaves the search operators unmodified, SEDIMA improves average final performance by 5.5% on AlgoTune and 6.6% on ALE-Bench LITE under a fixed budget of 100 evaluated candidates. Under OpenEvolve, SEDIMA requires 32.3% fewer iterations on average to reach baseline-best performance across the five evaluated backbones.
